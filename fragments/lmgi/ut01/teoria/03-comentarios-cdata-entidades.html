1.3 Comentarios, CDATA y caracteres especiales

XML permite incluir comentarios, escapar caracteres reservados y usar secciones CDATA para texto que no debe interpretarse como marcado.

Comentarios

Los comentarios sirven para dejar aclaraciones en el documento. No forman parte de los datos que una aplicacion deberia procesar.

<!-- Lista de alumnos matriculados en el modulo -->
<alumnos>
  <alumno id="A001">Nerea</alumno>
</alumnos>

Un comentario empieza con <!-- y termina con -->.

Caracteres especiales

Algunos caracteres tienen significado propio en XML. Si queremos usarlos como texto, debemos escribirlos mediante entidades.

Caracter Entidad Ejemplo de uso
< &lt; 3 &lt; 5
> &gt; 5 &gt; 3
& &amp; Java &amp; XML
" &quot; &quot;Hola&quot;
' &apos; &apos;Hola&apos;

Secciones CDATA

Una seccion CDATA permite escribir texto que contiene caracteres como < o & sin que el procesador XML los interprete como etiquetas o entidades.

<ejemplo>
  <![CDATA[
    if (edad < 18 && activo) {
      System.out.println("Menor activo");
    }
  ]]>
</ejemplo>

CDATA es util para incluir fragmentos de codigo, expresiones o texto tecnico. Aun asi, no debe usarse para evitar pensar la estructura del documento: los datos importantes deben seguir estando modelados con elementos y atributos.
