1.2 Elementos, etiquetas, atributos y contenido

La informacion de un XML se representa mediante elementos, formados por etiquetas, atributos y contenido.

Etiquetas y elementos

Una etiqueta es la marca que aparece entre los simbolos < y >. Un elemento incluye la etiqueta de apertura, el contenido y la etiqueta de cierre.

<nombre>Marta</nombre>

En el ejemplo, <nombre> es la etiqueta de apertura, </nombre> es la etiqueta de cierre y Marta es el contenido.

Tipos de contenido

Un elemento XML puede contener texto, otros elementos, una mezcla de ambos o no contener nada.

<ciudad>Pamplona</ciudad>

<alumno>
  <nombre>Iker</nombre>
  <curso>1 DAM</curso>
</alumno>

<linea />

La etiqueta <linea /> es un elemento vacio escrito de forma abreviada. Equivale a escribir <linea></linea>.

Atributos

Los atributos añaden informacion adicional a un elemento. Siempre aparecen dentro de la etiqueta de apertura y sus valores deben ir entre comillas.

<libro isbn="978-84-376-0494-7" idioma="es">
  <titulo>Don Quijote de la Mancha</titulo>
</libro>

En este caso, isbn e idioma son atributos del elemento <libro>.

¿Elemento o atributo?

No existe una unica respuesta correcta, pero esta regla practica suele ayudar:

Usa elementos para... Usa atributos para...
Datos principales del documento Metadatos o informacion auxiliar
Contenido largo o estructurado Identificadores, codigos o clasificaciones breves
Informacion que puede repetirse Propiedades simples de un elemento
