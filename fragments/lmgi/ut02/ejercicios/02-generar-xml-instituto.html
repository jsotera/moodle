2.2 Generar un XML válido a partir de un XSD

Actividad para practicar la lectura de un esquema XSD y construir un documento XML que cumpla sus reglas.

XSD de partida

Dado el siguiente esquema XSD, genera un documento XML válido:

<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <!-- Estructura principal y tipos referenciados -->
  <xs:element name="instituto">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="aulas">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="aula" type="xs:string" maxOccurs="unbounded" />
            </xs:sequence>
          </xs:complexType>
        </xs:element>

        <xs:element name="profesores">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="profesor" type="xs:string" maxOccurs="unbounded" />
            </xs:sequence>
          </xs:complexType>
        </xs:element>

        <xs:element name="alumnos">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="alumno" type="xs:string" maxOccurs="unbounded" />
            </xs:sequence>
          </xs:complexType>
        </xs:element>
      </xs:sequence>

      <xs:attribute name="nombreCentro" type="xs:string" use="optional" />
    </xs:complexType>
  </xs:element>
</xs:schema>

Antes de escribir el XML

Antes de empezar a escribir, analiza el XSD y responde mentalmente a estas preguntas:

  • ¿Cuál es el elemento raíz?
  • ¿Qué elementos deben aparecer dentro de la raíz?
  • ¿En qué orden deben aparecer?
  • ¿Qué elementos pueden repetirse varias veces?
  • ¿Hay algún atributo obligatorio u opcional?

Requisitos que debe cumplir tu XML

  • El elemento raíz debe ser <instituto>.
  • Debe contener los elementos <aulas>, <profesores> y <alumnos>.
  • Los elementos deben aparecer en el orden indicado por <xs:sequence>.
  • Dentro de <aulas> debe haber uno o varios elementos <aula>.
  • Dentro de <profesores> debe haber uno o varios elementos <profesor>.
  • Dentro de <alumnos> debe haber uno o varios elementos <alumno>.
  • El atributo nombreCentro es opcional, pero puedes incluirlo.

Tarea

Crea un archivo XML válido que cumpla el XSD anterior. Utiliza nombres inventados para las aulas, profesores y alumnos.

Después, valida el XML en Visual Studio Code usando el XSD como hicimos en el ejercicio anterior.

Comprobación adicional

Cuando tengas un XML válido, prueba a romperlo para comprobar que el validador detecta los errores:

  • Cambia el orden de <profesores> y <aulas>.
  • Elimina todos los elementos <aula>.
  • Cambia <alumno> por <estudiante>.
  • Escribe el atributo nombreCentro en otro elemento que no sea <instituto>.
