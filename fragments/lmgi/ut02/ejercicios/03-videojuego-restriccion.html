2.3 Videojuego: complexType con una restricción

Actividad para crear un XML válido a partir de un XSD con un complexType y una restricción sencilla.

XSD de partida

<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:element name="videojuego">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="titulo" type="xs:string" />
        <xs:element name="genero">
          <xs:simpleType>
            <xs:restriction base="xs:string">
              <xs:enumeration value="aventura" />
              <xs:enumeration value="deportes" />
              <xs:enumeration value="estrategia" />
              <xs:enumeration value="puzle" />
            </xs:restriction>
          </xs:simpleType>
        </xs:element>
      </xs:sequence>
    </xs:complexType>
  </xs:element>
</xs:schema>

Tarea

Genera un XML válido para este esquema. Después prueba a escribir un género que no esté en la enumeración y observa el error de validación.
