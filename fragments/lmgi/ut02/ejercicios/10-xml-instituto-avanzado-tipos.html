2.10 Instituto avanzado con tipos reutilizables

Actividad para construir un XML válido a partir de un XSD más completo, mezclando restricciones, atributos, tipos propios y estructuras anidadas.

Objetivo

Partimos de la idea del ejercicio anterior, pero ahora el esquema del instituto es más exigente. El XML deberá respetar tipos personalizados, atributos obligatorios, valores restringidos, expresiones regulares y elementos repetibles.

Lee el XSD con calma antes de escribir el XML. No intentes rellenar datos al azar: primero identifica la estructura general y después completa cada parte.

XSD de partida

<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:simpleType name="tipoIdPositivo">
    <xs:restriction base="xs:positiveInteger" />
  </xs:simpleType>

  <xs:simpleType name="tipoCodigoAula">
    <xs:restriction base="xs:string">
      <xs:pattern value="A[0-9][0-9][0-9]" />
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="tipoCodigoAlumno">
    <xs:restriction base="xs:string">
      <xs:pattern value="ALU-[0-9][0-9][0-9]" />
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="tipoCurso">
    <xs:restriction base="xs:string">
      <xs:enumeration value="1DAM" />
      <xs:enumeration value="1DAW" />
      <xs:enumeration value="2DAM" />
      <xs:enumeration value="2DAW" />
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="tipoEmail">
    <xs:restriction base="xs:string">
      <xs:pattern value=".+@.+" />
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="tipoHoras">
    <xs:restriction base="xs:integer">
      <xs:minInclusive value="1" />
      <xs:maxInclusive value="30" />
    </xs:restriction>
  </xs:simpleType>

  <xs:complexType name="tipoProfesorAsignado">
    <xs:sequence>
      <xs:element name="idProfesor" type="tipoIdPositivo" />
      <xs:element name="horasSemanales" type="tipoHoras" />
    </xs:sequence>
    <xs:attribute name="rol" use="required">
      <xs:simpleType>
        <xs:restriction base="xs:string">
          <xs:enumeration value="tutor" />
          <xs:enumeration value="docente" />
          <xs:enumeration value="apoyo" />
        </xs:restriction>
      </xs:simpleType>
    </xs:attribute>
  </xs:complexType>

  <xs:complexType name="tipoAulaAsignada">
    <xs:simpleContent>
      <xs:extension base="tipoCodigoAula">
        <xs:attribute name="principal" type="xs:boolean" use="optional" />
      </xs:extension>
    </xs:simpleContent>
  </xs:complexType>

  <xs:element name="instituto">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="aulas">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="aula" maxOccurs="unbounded">
                <xs:complexType>
                  <xs:sequence>
                    <xs:element name="nombre" type="xs:string" />
                    <xs:element name="capacidad">
                      <xs:simpleType>
                        <xs:restriction base="xs:integer">
                          <xs:minInclusive value="10" />
                          <xs:maxInclusive value="40" />
                        </xs:restriction>
                      </xs:simpleType>
                    </xs:element>
                    <xs:element name="profesoresAsignados">
                      <xs:complexType>
                        <xs:sequence>
                          <xs:element name="profesorAsignado" type="tipoProfesorAsignado" minOccurs="1" maxOccurs="unbounded" />
                        </xs:sequence>
                      </xs:complexType>
                    </xs:element>
                  </xs:sequence>
                  <xs:attribute name="codigo" type="tipoCodigoAula" use="required" />
                  <xs:attribute name="planta" type="xs:integer" use="optional" />
                </xs:complexType>
              </xs:element>
            </xs:sequence>
          </xs:complexType>
        </xs:element>

        <xs:element name="profesores">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="profesor" maxOccurs="unbounded">
                <xs:complexType>
                  <xs:sequence>
                    <xs:element name="nombre" type="xs:string" />
                    <xs:element name="email" type="tipoEmail" />
                    <xs:element name="departamento" type="xs:string" />
                  </xs:sequence>
                  <xs:attribute name="id" type="tipoIdPositivo" use="required" />
                </xs:complexType>
              </xs:element>
            </xs:sequence>
          </xs:complexType>
        </xs:element>

        <xs:element name="alumnos">
          <xs:complexType>
            <xs:sequence>
              <xs:element name="alumno" maxOccurs="unbounded">
                <xs:complexType>
                  <xs:sequence>
                    <xs:element name="nombre" type="xs:string" />
                    <xs:element name="curso" type="tipoCurso" />
                    <xs:element name="aulasAsignadas">
                      <xs:complexType>
                        <xs:sequence>
                          <xs:element name="aulaAsignada" type="tipoAulaAsignada" minOccurs="1" maxOccurs="unbounded" />
                        </xs:sequence>
                      </xs:complexType>
                    </xs:element>
                  </xs:sequence>
                  <xs:attribute name="codigo" type="tipoCodigoAlumno" use="required" />
                  <xs:attribute name="repetidor" type="xs:boolean" use="optional" />
                </xs:complexType>
              </xs:element>
            </xs:sequence>
          </xs:complexType>
        </xs:element>
      </xs:sequence>

      <xs:attribute name="nombreCentro" type="xs:string" use="required" />
      <xs:attribute name="cursoAcademico" type="xs:string" use="required" />
    </xs:complexType>
  </xs:element>
</xs:schema>

Pistas para leer el esquema

  • La raíz debe ser <instituto>.
  • <instituto> tiene dos atributos obligatorios: nombreCentro y cursoAcademico.
  • Dentro de <instituto> deben aparecer, en este orden: <aulas>, <profesores> y <alumnos>.
  • Cada profesor tiene un atributo id que debe ser un número entero positivo.
  • Las aulas tienen un atributo codigo con formato A001, A002, etc.
  • Los alumnos tienen un atributo codigo con formato ALU-001, ALU-002, etc.
  • Cada aula debe tener uno o varios profesores asignados.
  • Cada alumno debe tener una o varias aulas asignadas.
  • Los campos curso, rol, capacidad, horasSemanales y email tienen restricciones.

Tarea

Genera un XML válido que cumpla el XSD anterior. El XML debe incluir, como mínimo:

  • Dos aulas.
  • Dos profesores.
  • Tres alumnos.
  • Al menos un aula con más de un profesor asignado.
  • Al menos un alumno asignado a más de un aula.
  • Al menos un atributo opcional utilizado, como planta, principal o repetidor.

Valida el XML con Visual Studio Code y las extensiones instaladas en el ejercicio anterior.

Pruebas de error

Cuando tengas un XML válido, provoca algunos errores para comprobar que entiendes las reglas:

  • Usa un código de aula como 101 en lugar de A101.
  • Usa un código de alumno como ALUMNO-001 en lugar de ALU-001.
  • Escribe una capacidad menor que 10 o mayor que 40.
  • Utiliza un rol de profesor asignado que no sea tutor, docente o apoyo.
  • Quita todos los profesores asignados de un aula.
  • Escribe un email sin @.
  • Cambia el orden de <aulas>, <profesores> y <alumnos>.
