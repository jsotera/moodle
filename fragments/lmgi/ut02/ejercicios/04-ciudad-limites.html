2.4 Ciudad: límites numéricos

Actividad para crear un XML válido aplicando límites mínimos y máximos en valores numéricos.

XSD de partida

<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:element name="ciudad">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="nombre" type="xs:string" />
        <xs:element name="habitantes">
          <xs:simpleType>
            <xs:restriction base="xs:integer">
              <xs:minInclusive value="1" />
              <xs:maxInclusive value="10000000" />
            </xs:restriction>
          </xs:simpleType>
        </xs:element>
        <xs:element name="temperaturaMedia">
          <xs:simpleType>
            <xs:restriction base="xs:decimal">
              <xs:minInclusive value="-30" />
              <xs:maxInclusive value="50" />
            </xs:restriction>
          </xs:simpleType>
        </xs:element>
      </xs:sequence>
    </xs:complexType>
  </xs:element>
</xs:schema>

Tarea

Genera un XML válido para una ciudad. Después prueba valores fuera de rango, como 0 habitantes o una temperatura media de 80.
