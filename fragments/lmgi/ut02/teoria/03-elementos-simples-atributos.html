2.3 Elementos simples, tipos de datos y atributos

XSD permite indicar qué elementos existen, qué tipo de dato contienen y qué atributos pueden usar.

Elementos simples

Un elemento simple contiene texto, pero no contiene otros elementos ni atributos propios.

<nombre>Ane</nombre>
<edad>17</edad>
<fechaNacimiento>2009-04-18</fechaNacimiento>

En XSD se pueden definir así:

<xs:element name="nombre" type="xs:string" />
<xs:element name="edad" type="xs:integer" />
<xs:element name="fechaNacimiento" type="xs:date" />

Tipos de datos habituales

Tipo XSD Qué representa Ejemplo válido
xs:string Texto Ane
xs:integer Número entero 17
xs:decimal Número con decimales 8.75
xs:boolean Verdadero o falso true, false, 1, 0
xs:date Fecha 2026-09-24

Atributos

Los atributos también pueden declararse en XSD. Normalmente se definen dentro de un tipo complejo, porque pertenecen a un elemento.

<alumno id="A001">
  <nombre>Ane</nombre>
</alumno>
<xs:attribute name="id" type="xs:string" use="required" />

El atributo use="required" indica que ese atributo es obligatorio. Si no aparece en el XML, el documento no será válido respecto al XSD.
