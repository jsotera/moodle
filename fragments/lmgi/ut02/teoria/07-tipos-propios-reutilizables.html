2.7 Definir tipos propios y reutilizarlos

XSD permite crear tipos propios para reutilizar reglas en distintas partes del esquema.

Por qué crear tipos propios

Si una misma regla aparece varias veces, no tiene sentido escribirla una y otra vez. En XSD podemos definir un tipo una sola vez y reutilizarlo después.

Esto hace que el esquema sea más claro, más fácil de mantener y menos propenso a errores.

Tipos simples propios

Un tipo simple propio sirve para dar nombre a una restricción. Por ejemplo, podemos definir un tipo para notas entre 0 y 10.

<xs:simpleType name="tipoNota">
  <xs:restriction base="xs:decimal">
    <xs:minInclusive value="0" />
    <xs:maxInclusive value="10" />
  </xs:restriction>
</xs:simpleType>

Después, podemos reutilizarlo en varios elementos:

<xs:element name="notaProgramacion" type="tipoNota" />
<xs:element name="notaMarcas" type="tipoNota" />
<xs:element name="notaBasesDatos" type="tipoNota" />

Si más adelante cambiamos el rango de notas, solo tendremos que modificar tipoNota.

Otro tipo simple: código de alumno

También podemos crear un tipo propio para un patrón concreto:

<xs:simpleType name="tipoCodigoAlumno">
  <xs:restriction base="xs:string">
    <xs:pattern value="A[0-9][0-9][0-9]" />
  </xs:restriction>
</xs:simpleType>

Y usarlo, por ejemplo, en un atributo:

<xs:attribute name="id" type="tipoCodigoAlumno" use="required" />

Tipos complejos propios

Los tipos complejos propios sirven para reutilizar estructuras completas. Por ejemplo, podemos definir una dirección una vez:

<xs:complexType name="tipoDireccion">
  <xs:sequence>
    <xs:element name="calle" type="xs:string" />
    <xs:element name="numero" type="xs:string" />
    <xs:element name="codigoPostal">
      <xs:simpleType>
        <xs:restriction base="xs:string">
          <xs:pattern value="[0-9][0-9][0-9][0-9][0-9]" />
        </xs:restriction>
      </xs:simpleType>
    </xs:element>
    <xs:element name="localidad" type="xs:string" />
  </xs:sequence>
</xs:complexType>

Y después usarla en distintos elementos:

<xs:element name="direccionAlumno" type="tipoDireccion" />
<xs:element name="direccionCentro" type="tipoDireccion" />

Ejemplo completo con tipos reutilizables

Este XML utiliza una estructura de alumno con dirección y notas:

<alumno id="A125">
  <nombre>Nerea</nombre>
  <direccion>
    <calle>Calle Mayor</calle>
    <numero>12</numero>
    <codigoPostal>31001</codigoPostal>
    <localidad>Pamplona</localidad>
  </direccion>
  <notaProgramacion>8.5</notaProgramacion>
  <notaMarcas>9</notaMarcas>
</alumno>

Un esquema XSD con tipos propios podría ser:

<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:simpleType name="tipoCodigoAlumno">
    <xs:restriction base="xs:string">
      <xs:pattern value="A[0-9][0-9][0-9]" />
    </xs:restriction>
  </xs:simpleType>

  <xs:simpleType name="tipoNota">
    <xs:restriction base="xs:decimal">
      <xs:minInclusive value="0" />
      <xs:maxInclusive value="10" />
    </xs:restriction>
  </xs:simpleType>

  <xs:complexType name="tipoDireccion">
    <xs:sequence>
      <xs:element name="calle" type="xs:string" />
      <xs:element name="numero" type="xs:string" />
      <xs:element name="codigoPostal" type="xs:string" />
      <xs:element name="localidad" type="xs:string" />
    </xs:sequence>
  </xs:complexType>

  <xs:element name="alumno">
    <xs:complexType>
      <xs:sequence>
        <xs:element name="nombre" type="xs:string" />
        <xs:element name="direccion" type="tipoDireccion" />
        <xs:element name="notaProgramacion" type="tipoNota" />
        <xs:element name="notaMarcas" type="tipoNota" />
      </xs:sequence>
      <xs:attribute name="id" type="tipoCodigoAlumno" use="required" />
    </xs:complexType>
  </xs:element>
</xs:schema>

Reglas prácticas

  • Usa <xs:simpleType> propio cuando quieras reutilizar una restricción sobre texto, números, fechas, patrones o enumeraciones.
  • Usa <xs:complexType> propio cuando quieras reutilizar una estructura con elementos hijos o atributos.
  • Los tipos propios se declaran normalmente dentro de <xs:schema>, antes de utilizarlos.
  • Para usar un tipo propio, escribe su nombre en el atributo type.
