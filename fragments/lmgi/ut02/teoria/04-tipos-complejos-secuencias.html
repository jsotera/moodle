2.4 Tipos complejos y secuencias

Los tipos complejos permiten definir elementos que contienen otros elementos, atributos o ambas cosas.

Elementos con otros elementos dentro

Muchos documentos XML tienen elementos que agrupan información. Por ejemplo, un elemento <alumno> puede contener <nombre>, <edad> y <curso>.

<alumno>
  <nombre>Ane</nombre>
  <edad>17</edad>
  <curso>1 DAM</curso>
</alumno>

En XSD, ese elemento se define con <xs:complexType>:

<xs:element name="alumno">
  <xs:complexType>
    <xs:sequence>
      <xs:element name="nombre" type="xs:string" />
      <xs:element name="edad" type="xs:integer" />
      <xs:element name="curso" type="xs:string" />
    </xs:sequence>
  </xs:complexType>
</xs:element>

La importancia del orden

<xs:sequence> indica que los elementos hijos deben aparecer en el mismo orden en el que se han declarado.

XML Resultado Motivo
<nombre>, <edad>, <curso> Válido Respeta el orden del XSD.
<edad>, <nombre>, <curso> No válido No respeta la secuencia definida.

Repeticiones y obligatoriedad

Con minOccurs y maxOccurs podemos indicar cuántas veces puede aparecer un elemento.

Si no escribimos estos atributos, XSD entiende que el elemento debe aparecer exactamente una vez.

<xs:element name="telefono" type="xs:string" minOccurs="0" maxOccurs="unbounded" />

Este ejemplo indica que <telefono> puede no aparecer, aparecer una vez o aparecer muchas veces.

Atributo Qué controla Valores habituales Valor por defecto
minOccurs Número mínimo de veces que debe aparecer el elemento. 0, 1, 2, 3... 1
maxOccurs Número máximo de veces que puede aparecer el elemento. 1, 2, 3..., unbounded 1

La palabra unbounded significa que no hay un límite máximo concreto: el elemento puede repetirse tantas veces como sea necesario.

Definición Cómo se interpreta Ejemplo de uso
minOccurs="1" maxOccurs="1" Debe aparecer exactamente una vez. Un nombre obligatorio.
minOccurs="0" maxOccurs="1" Puede no aparecer, pero si aparece solo puede hacerlo una vez. Un segundo apellido opcional.
minOccurs="0" maxOccurs="unbounded" Puede no aparecer o puede aparecer muchas veces. Una lista opcional de teléfonos.
minOccurs="1" maxOccurs="unbounded" Debe aparecer al menos una vez y puede repetirse. Una lista de módulos matriculados.
minOccurs="2" maxOccurs="4" Debe aparecer como mínimo dos veces y como máximo cuatro. Entre dos y cuatro ejercicios entregados. 
<xs:element name="nombre" type="xs:string" />
<!-- Equivale a minOccurs="1" maxOccurs="1" -->

<xs:element name="segundoApellido" type="xs:string" minOccurs="0" maxOccurs="1" />
<!-- Opcional: puede no salir -->

<xs:element name="telefono" type="xs:string" minOccurs="0" maxOccurs="unbounded" />
<!-- Opcional y repetible -->
