3.7 Reproducción de webs a partir de capturas

Practica con dos propuestas de estilo examen: observa las capturas de una web y construye sus páginas utilizando el HTML trabajado en la unidad.

De la captura al HTML

En estas actividades no tendrás una lista de etiquetas que debas colocar. El modelo será el documento PDF de cada proyecto: tendrás que reconocer sus contenidos, decidir qué etiquetas los representan y organizar los archivos necesarios.

  1. Revisa todas las capturas del documento antes de empezar. Identifica las páginas, sus apartados y los elementos que se repiten.
  2. Localiza encabezados, párrafos, formatos de texto, listas, imágenes, enlaces, tablas y formularios que aparezcan en el modelo.
  3. Prepara los archivos HTML y las imágenes. Después construye cada página por apartados.
  4. Compara el resultado en el navegador con las capturas y corrige las diferencias y los elementos que falten.

El objetivo es reproducir los contenidos, su orden y su estructura con las etiquetas adecuadas, no conseguir una copia exacta al píxel mediante CSS que todavía no hemos estudiado.

Preparación y criterios comunes

  • Crea una carpeta independiente para cada proyecto, con una página inicial index.html y una subcarpeta img para las imágenes.
  • Si el modelo muestra varias páginas, crea un archivo HTML para cada una y conéctalas con enlaces relativos.
  • Cada documento tendrá estructura HTML completa, idioma español, codificación UTF-8 y un título de pestaña adecuado.
  • Reproduce los textos legibles y su jerarquía con encabezados, párrafos y las etiquetas de formato que correspondan. No simules la separación de apartados acumulando espacios o saltos de línea.
  • Si aparecen tablas, constrúyelas con filas y celdas reales. Utiliza cabeceras y, cuando corresponda, colspan y rowspan. Puedes reutilizar el CSS de bordes de la teoría 3.3 dentro de style en el head.
  • Si aparecen formularios, utiliza controles reales: etiquetas asociadas con for e id, tipos de campo adecuados, nombres de envío y grupos de opciones coherentes. No es necesario programar un servidor ni almacenar los datos.
  • No utilices Bootstrap, JavaScript ni plantillas de páginas ya construidas: el trabajo consiste en aplicar el HTML de esta unidad.

Obtener las imágenes

Las imágenes que necesites debes obtenerlas de los propios pantallazos del PDF. Haz una captura, recorta únicamente la imagen que quieras utilizar y guárdala en la carpeta img con un nombre descriptivo.

Inserta cada recorte mediante <img>, con una ruta relativa y un texto alt adecuado. Ajusta sus dimensiones sin deformarlo.

Importante: los recortes sirven para las imágenes de la web, no para sustituir la página entera ni sus textos, tablas o formularios. Esos elementos debes construirlos con HTML.

Revisión final

  • ¿Están todas las páginas y los apartados que aparecen en el documento?
  • ¿Los textos, las listas y las tablas están construidos con HTML, en lugar de ser imágenes?
  • ¿Los enlaces funcionan y las imágenes se cargan desde rutas relativas?
  • ¿Las tablas conservan sus filas, columnas y combinaciones de celdas?
  • ¿Los formularios, si los hay, permiten escribir y seleccionar opciones correctamente?
  • ¿El proyecto sigue funcionando si mueves su carpeta completa a otra ubicación?
