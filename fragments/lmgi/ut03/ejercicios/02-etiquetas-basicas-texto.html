3.2 Ejercicios de etiquetas básicas de texto

Actividades incrementales para practicar títulos, párrafos, texto en línea y listas.

Actividad 1: jerarquía de títulos

Crea un archivo llamado texto-01.html sobre un tema que te interese.

  • Utiliza un único <h1> como título principal.
  • Utiliza al menos dos <h2> para secciones principales.
  • Utiliza al menos dos <h3> para subsecciones.
  • No elijas los encabezados por su tamaño visual, sino por la importancia del contenido.

Actividad 2: párrafos y saltos de línea

Crea un archivo llamado texto-02.html con tres párrafos sobre una película, serie, videojuego o libro.

  • Utiliza la etiqueta <p> para cada párrafo.
  • Incluye un salto de línea con <br> en uno de los párrafos.
  • Añade una separación temática con <hr>.
  • Comprueba la diferencia entre crear un párrafo nuevo y usar un salto de línea.

Actividad 3: destacar texto correctamente

Crea un archivo llamado texto-03.html con un pequeño texto de avisos para el aula.

  • Usa <strong> para marcar información realmente importante.
  • Usa <b> para resaltar una palabra solo de forma visual.
  • Usa <em> para dar énfasis a una frase.
  • Usa <i> para una palabra extranjera, técnica o especial.

Al final del archivo, añade un comentario explicando la diferencia entre <strong> y <b>.

Actividad 4: listas ordenadas y no ordenadas

Crea un archivo llamado texto-04.html con dos listas.

  • Una lista no ordenada con materiales necesarios para trabajar HTML.
  • Una lista ordenada con los pasos para crear y abrir una página HTML.
  • Cada elemento debe estar dentro de una etiqueta <li>.
  • Añade un título antes de cada lista.

Actividad 5: miniartículo HTML

Crea un archivo llamado texto-05.html con un miniartículo sobre una tecnología, afición o tema de actualidad.

  • Debe tener una estructura HTML completa.
  • Debe incluir títulos jerárquicos.
  • Debe incluir varios párrafos.
  • Debe usar <span> para marcar una palabra o expresión concreta.
  • Debe incluir texto destacado con <strong> y texto enfatizado con <em>.
  • Debe incluir al menos una lista.
