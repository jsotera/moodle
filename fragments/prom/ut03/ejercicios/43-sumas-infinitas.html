3.34 Sumas infinitas

En esta actividad emplearemos la clase Scanner para leer datos que el usuario introduzca desde el teclado.

En este ejercicio, el usuario podrá introducir números enteros para realizar una suma acumulativa. Mientras no introduzca un 0, el programa seguirá sumando los números ingresados. Cuando el usuario introduzca un 0, el programa mostrará el total de la suma y finalizará.

Nombre del proyecto del ejercicio: UT3Ejer34SumasInfinitas
