3.8 Juego de dados

Decide quién gana una partida en la que un trío tiene prioridad sobre la suma.

Qué debes hacer

Representa a dos participantes mediante sus nombres y seis variables enteras locales: tres dados por participante. Todo el programa se desarrolla dentro de main.

  1. Asigna inicialmente valores entre 1 y 6 para poder probar las reglas.
  2. Muestra los tres dados y la suma de cada participante.
  3. Si solo una persona tiene los tres dados iguales, gana esa persona, independientemente de las sumas.
  4. Si ambas tienen trío, gana quien tenga el valor de dado más alto; si los tríos son iguales, hay empate.
  5. Si ninguna tiene trío, gana la suma mayor; si las sumas coinciden, hay empate.

Cuando funcionen las decisiones, sustituye las asignaciones por tiradas con Random o Math.random(). No necesitas arrays ni una clase Jugador.

Pruebas

Comprueba 2, 2, 2 contra 6, 6, 5; dos tríos diferentes; dos tríos iguales; y dos tiradas sin trío con la misma suma.

Nombre del proyecto del ejercicio: UT3Ejer8Dados
