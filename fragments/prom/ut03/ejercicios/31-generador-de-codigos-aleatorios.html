3.24 Generador de Códigos Aleatorios

Genera un código aleatorio de cifras con una longitud indicada por teclado.

Dentro de main, solicita un entero positivo y guárdalo en int longitud. Si no es positivo, muestra un aviso y no generes el código.

Para una longitud válida, comienza con String codigo = "". Utiliza un for para generar tantas cifras aleatorias entre 0 y 9 como indique la longitud y concatenarlas al texto. Al terminar, muestra el código completo.

Puedes utilizar Random o Math.random(). Conserva el código como texto para no perder posibles ceros iniciales. No crees una clase GeneradorCodigo ni un método propio.

Nombre del proyecto del ejercicio: UT3Ejer24GeneradorCodigo
