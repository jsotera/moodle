Condicionales Simples

En esta actividad trabajaremos los condicionales simples utilizando operadores como >, <, >= y <=. Aprenderemos a utilizar if, else if y else para evaluar condiciones básicas.

Crearás proyectos donde implementarás condiciones sencillas para resolver problemas prácticos como verificar si un número es mayor o menor, si un objeto tiene ciertos atributos o si una persona cumple una serie de requisitos.

Forma de trabajo en la tanda inicial

Resuelve los primeros 40 ejercicios, de condicionales, for y while, dentro del método main de una clase Main. Utiliza variables locales, constantes, expresiones y estructuras de control. Puedes emplear Scanner, Random y Math, pero en esos ejercicios no declares clases de modelo, atributos, constructores ni métodos auxiliares propios. Tampoco necesitas arrays ni colecciones.

Los ejercicios están organizados en tres bloques, con sus subsecciones introductorias: condicionales (3.1–3.18), bucles for (3.19–3.33) y bucles while (3.34–3.40). Crea un proyecto independiente para cada ejercicio.

Después del 3.40 encontrarás las actividades JavaFX (3.41–3.45) y los proyectos finales con clases y consola (3.46–3.48). En esas tandas completarás los métodos indicados en cada proyecto base.
