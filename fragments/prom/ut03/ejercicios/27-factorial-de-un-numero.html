3.21 Factorial de un Número

En este ejercicio calcularás el factorial de un número introducido por el usuario.

El factorial de un número entero positivo se define como el producto de todos los números enteros positivos menores o iguales a ese número. Por ejemplo, el factorial de 5 (representado como 5!) es 5 × 4 × 3 × 2 × 1 = 120. El factorial de 0 es 1 por definición.

Desde la clase Main, solicita al usuario que ingrese un número y utiliza un bucle for para calcular el factorial de dicho número e imprimir el resultado.

Solicita un entero entre 0 y 20, ambos incluidos. Si está fuera del intervalo, muestra un aviso y no calcules el factorial. Utiliza un acumulador long: el límite de 20 evita que el resultado supere su capacidad.

Nombre del proyecto del ejercicio: UT3Ejer21FactorialUsuario
