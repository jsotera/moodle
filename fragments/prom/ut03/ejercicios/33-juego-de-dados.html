3.26 Juego de Dados

En este ejercicio crearás un juego de dados para dos jugadores, donde competirán en varias rondas.

Desde main, simula 10 rondas con un for. Representa a los dos participantes con sus nombres y dos contadores locales de puntuación que comiencen en cero.

  1. En cada ronda, genera dos dados por participante, con valores enteros aleatorios entre 1 y 6.
  2. Muestra los cuatro dados y compara la suma de cada pareja.
  3. Quien obtenga la suma mayor gana un punto. Si las sumas coinciden, la ronda termina en empate y nadie suma puntos.
  4. Muestra las puntuaciones acumuladas después de cada ronda.
  5. Después de las 10 rondas, anuncia quién tiene más puntos o si hay empate final.

Utiliza Random o Math.random(), sin crear una clase JuegoDados ni un método para lanzar dados. Todas las tiradas y comparaciones van dentro de main.

Nombre del proyecto del ejercicio: UT3Ejer26JuegoDados
