3.35 Suma de Números Pares

En este ejercicio, el usuario podrá introducir números enteros. El programa sumará únicamente los números pares. Si el usuario introduce un número impar, el programa mostrará el resultado total de la suma y finalizará.

Con este ejercicio, podrás ver cómo se puede utilizar el bucle while para validar entradas del usuario y tomar decisiones basadas en condiciones dentro del bucle.

El primer impar sirve solo para terminar y no se suma. El cero es par: no termina la lectura. Admite también enteros negativos y, si el primer dato es impar, muestra una suma de cero.

Nombre del proyecto del ejercicio: UT3Ejer35SumasPares
