3.37 Juego de Aritmética: ¡Acierta 5 Preguntas!

En esta actividad, vamos a desarrollar un programa que pondrá a prueba tus habilidades en aritmética básica a través de operaciones de suma y resta generadas aleatoriamente.

Objetivo

El programa generará preguntas aleatorias de suma y resta entre dos números aleatorios (entre 0 y 100), y las mostrará en pantalla hasta que el usuario acierte 5 preguntas en total.

Estructura del Programa

Para este ejercicio, deberás implementar lo siguiente:

  • Un bucle que genere operaciones aleatorias de suma o resta entre dos números aleatorios.
  • Validación de la respuesta del usuario, indicando si es correcta o incorrecta tras cada intento.
  • Una condición para finalizar el programa una vez que el usuario haya acertado 5 preguntas.

¿Qué debes hacer?

Sigue estos pasos:

  • Usa Math.random() para generar dos operandos enteros entre 0 y 100, ambos incluidos, y elegir si la pregunta será una suma o una resta. Las restas pueden tener resultado negativo.
  • Implementa un bucle while que se ejecute hasta que el usuario acumule 5 aciertos.
  • Emplea una constante local final int para definir la cantidad de aciertos que se deben obtener para finalizar el cuestionario.
  • Informa al usuario cada vez que su respuesta sea correcta o incorrecta.
  • Finaliza el programa mostrando un mensaje de felicitación una vez que el usuario haya acertado 5 preguntas.

Los aciertos no tienen que ser consecutivos. Un error no resta aciertos: genera una nueva pregunta y continúa hasta alcanzar el objetivo.
