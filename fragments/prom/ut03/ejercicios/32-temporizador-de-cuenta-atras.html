3.25 Temporizador de Cuenta Atrás

Simula un temporizador de cuenta atrás con un bucle descendente.

Solicita en main un entero no negativo y guárdalo en tiempoInicial. Si es negativo, muestra un aviso. En otro caso, utiliza un for para mostrar los valores desde ese tiempo hasta cero, ambos incluidos. Después muestra que la cuenta atrás ha terminado.

No crees una clase Temporizador ni un método propio. Opcionalmente, utiliza Thread.sleep(1000); entre un valor y el siguiente para esperar un segundo. No hace falta esperar después del cero.

Solo si incorporas esa espera, puedes usar esta firma para el método principal:

public static void main(String[] args) throws InterruptedException {
    // Aqui escribiras la cuenta atras.
}

sleep recibe milisegundos. InterruptedException es una excepción estándar de Java; en esta ampliación la declaración throws permite comunicar una interrupción de la espera sin crear métodos ni excepciones propios.
