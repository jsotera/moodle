3.17 Calculadora con switch

Reformula la calculadora utilizando switch para seleccionar operaciones.

Qué debes hacer

Solicita dentro de main dos números double y uno de los operadores +, -, * o /.

  • Utiliza switch para seleccionar el cálculo.
  • Dentro del caso de división, comprueba el divisor con un condicional. Si es cero, informa del problema sin dividir.
  • Incluye default para los operadores desconocidos.
  • Si utilizas la sintaxis con case:, evita que se ejecuten accidentalmente los casos siguientes.

Pruebas

Prueba las cuatro operaciones, un operador desconocido, una división entre cero y varias operaciones consecutivas. Compara los resultados con los del ejercicio 3.13.

Nombre del proyecto del ejercicio: UT3Ejer17Calculadora
