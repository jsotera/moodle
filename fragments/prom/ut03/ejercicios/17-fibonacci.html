3.17 Serie de Fibonacci

Calcula una sucesión conservando únicamente los dos valores anteriores.

Qué debes hacer

La sucesión comienza con F(0) = 0 y F(1) = 1. Cada término siguiente es la suma de los dos anteriores: 0, 1, 1, 2, 3, 5, 8, 13....

  1. Solicita una posición entera n entre 0 y 92. Repite la petición mientras el valor no sea válido.
  2. Muestra los términos desde la posición 0 hasta la posición n, ambas incluidas, mediante un bucle.
  3. Indica al final cuál es el valor de F(n).

Trabaja solo dentro de main, con variables long para los términos y una variable temporal para actualizar los valores sin perder información. No utilices recursividad, arrays ni métodos auxiliares.

El límite evita que el término solicitado supere la capacidad de long. Ten cuidado: tampoco debes calcular un término posterior fuera de rango que no vayas a mostrar.

Pruebas

Prueba n = 0, 1, 2, 7 y 92. Para n = 7 deben aparecer ocho términos, porque comenzamos a contar en la posición cero.
