3.13 Calculadora con condicionales

Selecciona una operación aritmética mediante if y else if.

Qué debes hacer

Dentro de main, solicita por teclado dos números double y una operación de tipo String: "+", "-", "*" o "/".

  • Utiliza una cadena de condicionales para elegir la operación y mostrar su resultado.
  • Compara los símbolos con equals().
  • Si se solicita una división cuyo segundo número sea cero, muestra un aviso y no realices la división.
  • Si el símbolo no corresponde a ninguna operación, informa de ello sin mostrar un resultado numérico inventado.

No crees una clase Calculadora ni métodos para las operaciones.

Pruebas

Prueba las cuatro operaciones, una división con decimales, una división entre cero y un operador desconocido.

Nombre del proyecto del ejercicio: UT3Ejer13Calculadora
