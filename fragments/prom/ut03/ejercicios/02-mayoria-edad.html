3.2 Edad y mayoría de edad

Utiliza una condición para decidir si una persona ha alcanzado la mayoría de edad.

Qué debes hacer

Dentro de main, declara String nombre e int edad. No necesitas crear una clase Persona.

  • Si la edad es negativa, muestra que el dato no es válido.
  • Si la edad es de 18 años o más, muestra el nombre e indica que es mayor de edad.
  • En los demás casos, muestra el nombre e indica que es menor de edad.

Después de resolverlo con if y else, escribe una segunda versión para edades válidas empleando el operador ternario ?:.

Pruebas

Comprueba las edades -1, 0, 17, 18 y 19. Un dato no válido no debe recibir además una clasificación de mayoría de edad.

Nombre del proyecto del ejercicio: UT3Ejer2MayorEdad
