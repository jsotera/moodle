Más ejercicios!

Aumentaremos la complejidad combinando bucles, condicionales, números aleatorios y acumuladores, junto con los conocimientos de las unidades anteriores.

Representa los datos mediante variables locales dentro de main. Aunque el enunciado describa jugadores, guerreros o caballos, no tendrás que crear clases para representarlos.

Estos ejercicios nos permitirán:

  • Simular interacciones entre participantes mediante sus datos y decisiones.
  • Utilizar bucles y condicionales para manejar casos complejos.
  • Reforzar las expresiones, las constantes y las llamadas a métodos de las clases de Java.
