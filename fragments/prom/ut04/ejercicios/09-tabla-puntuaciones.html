4.9 Tabla de puntuaciones

En esta actividad, vamos a seguir practicando con cadenas de texto y colores en consola. Además, utilizaremos el método printf para alinear el texto y mostrar una tabla de puntuaciones de forma elegante.

Descripción del Proyecto

Vais a desarrollar un programa que muestre puntuaciones generadas aleatoriamente (valores entre 0 y 200) y nombres asignados a dichas puntuaciones introducidos por el usuario con la clase Scanner. Es decir, se introducirá un nombre y se generará una puntuación aleatoria asignada a dicho nombre. Cuando el usuario introduzca una palabra vacía el programa dejará de solicitar más nombres y mostrará una tabla con tres columnas: Jugador, Puntuación y Rango. El rango estará coloreado según la puntuación del jugador:

  • Puntuación menor a 50: color ROJO.
  • Puntuación entre 50 y 100: color AMARILLO.
  • Puntuación mayor a 100: color VERDE.

Ejemplo de Salida

------------------------------------------------
| Jugador           | Puntuación  | Rango      |
------------------------------------------------
| Alice             |         120 | VERDE      |
| Bob               |          45 | ROJO       |
| Charlie           |          75 | AMARILLO   |
| David             |         200 | VERDE      |
------------------------------------------------

En este ejemplo:

  • La columna de Jugador está alineada a la izquierda.
  • La columna de Puntuación está alineada a la derecha.
  • La columna de Rango muestra el color correspondiente usando las constantes de la clase ColoresConsola.

Requisitos

  • Utilizad la clase ColoresConsola creada anteriormente para aplicar colores en la columna de rango.
  • Debéis formatear la tabla utilizando printf para asegurar que las columnas estén alineadas correctamente.
  • Al menos tres jugadores con puntuaciones diferentes.
  • El texto debe quedar formateado de manera limpia y legible.

Pistas

  • Utilizad %s para formatear cadenas de texto, %d para números enteros y %n para saltos de línea.
  • Podéis alinear texto a la izquierda usando %-20s y a la derecha con %20s (por ejemplo).
