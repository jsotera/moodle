4.15 Partido de fútbol

En esta actividad vamos a simular un partido de fútbol entre jugadores y porteros, utilizando todo lo aprendido sobre paso por referencia, probabilidad y relaciones entre objetos.

Tendrás que diseñar las clases Jugador y Portero con los métodos y atributos necesarios para que el balón pueda ir pasando de unos a otros, y los eventos (pases, regates y chutes) ocurran según las probabilidades establecidas.

Clases principales

  • Jugador: representa a un jugador de campo.
  • Portero: representa al guardameta de un equipo.

Ambos interactúan entre sí y con el balón, que estará “dentro” de un objeto en forma de atributo booleano (tieneBalon).

Atributos sugeridos

Para la clase Jugador puedes considerar los siguientes atributos:

  • String nombre — nombre del jugador.
  • Jugador compi — compañero de equipo al que puede pasar el balón.
  • boolean tieneBalon — indica si el jugador tiene el balón actualmente.
  • int tasaExitoPase — probabilidad (1–100) de completar un pase con éxito.
  • int tasaExitoGol — probabilidad (1–100) de que su chute sea certero y llegue a portería.
  • int tasaInterceptar — probabilidad (1–100) de interceptar un pase o un regate rival.
  • int tasaRegate — probabilidad (1–100) de regatear con éxito a un rival.

Y para la clase Portero:

  • String nombre
  • boolean tieneBalon
  • int tasaParada — probabilidad (1–100) de detener un disparo.
  • int tasaExitoPase — probabilidad de realizar un pase correcto al iniciar jugada.
💡 Nota: Puedes ajustar las probabilidades libremente para que el partido sea equilibrado y entretenido.

Métodos requeridos

Cada clase debe tener los siguientes métodos:

En Jugador:
  • void regatear(Jugador rival) — el jugador intenta superar al rival.
  • void chutar(Portero porteroRival) — intenta marcar un gol al portero contrario.
  • void pasar(Jugador destino, Jugador rival) — intenta pasar el balón a su compañero evitando la intercepción.
  • String toString() — devuelve una descripción del jugador, su tasa de éxito y si tiene el balón.
En Portero:
  • void pararBalon() — determina si consigue detener el disparo.
  • void pasar(Jugador destino) — el portero pasa el balón a un jugador de su equipo.
  • String toString() — muestra su tasa de parada y si tiene el balón.

Cada acción debe modificar correctamente el atributo tieneBalon de los jugadores implicados, para reflejar quién controla el balón en cada momento.

Lógica del partido

Se simulará un pequeño partido o secuencia de jugadas:

  • Comienza con un jugador que tiene el balón (tieneBalon = true).
  • El jugador puede decidir aleatoriamente si regatea, pasa o chuta.
  • Los rivales intentan interceptar el balón o detener el disparo, según corresponda.
  • Si el balón se pierde, cambia la posesión automáticamente.

Utiliza Math.random() para generar los porcentajes de éxito o fallo. Por ejemplo: if (Math.random() * 100 < tasaExitoPase) ...

⚠️ Recuerda que los métodos deben afectar a ambos objetos involucrados. Si un jugador falla un pase, su compañero no recibe el balón y el rival puede recuperarlo.

Presentación y formato

  • Utiliza printf() para mostrar mensajes de manera formateada, con colores si usas la clase de colores del ejercicio anterior.
  • Muestra mensajes claros, por ejemplo:
    "Juan intenta regatear a Carlos y... ¡Lo consigue!"
    "El portero Paco detiene el disparo de Juan con una gran parada."
  • Incluye un marcador global (goles Equipo1 vs Equipo2).

Retos adicionales

  • Permite que el partido dure varios turnos (por ejemplo, 10 jugadas).
  • Agrega una clase Equipo que contenga varios jugadores y su portero, para simular equipos completos.
  • Implementa un método iniciarPartido() que automatice el flujo y declare el equipo ganador al final.
  • Agrega una estadística final con el número de pases, regates, tiros y goles exitosos.
  • Si te sientes valiente, puedes incluir una clase Arbitro e incluir un sistema de faltas y tarjetas (esto sería una gran ampliación)
