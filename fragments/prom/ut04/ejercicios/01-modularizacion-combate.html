4.1 Modularización: combate de personajes

En esta actividad aprenderás a modularizar código. Partiremos de una clase Codigo1 que contiene todo en un único método y varios atributos, y la tarea será reorganizarla en clases y métodos coherentes con nombres claros y responsables.

Código base a modularizar

Esta es la clase que vamos a usar como punto de partida:

public class Codigo1 {

    public String nombre1;
    public int vida1;
    public int ataque1;
    public int defensa1;

    public String nombre2;
    public int vida2;
    public int ataque2;
    public int defensa2;

    public void blablabla() {

        nombre1 = "R2D2";
        vida1 = 100;
        ataque1 = (int) (Math.random() * 10) + 5;
        defensa1 = (int) (Math.random() * 10) + 5;

        nombre2 = "C3P0";
        vida2 = 100;
        ataque2 = (int) (Math.random() * 10) + 5;
        defensa2 = (int) (Math.random() * 10) + 5;

        System.out.println("Comienza el combate");

        while(vida1>0 && vida2>0) {

            System.out.println("Recalculando stats");

            ataque1 = (int) (Math.random() * 10) + 5;
            defensa1 = (int) (Math.random() * 10) + 5;

            ataque2 = (int) (Math.random() * 10) + 5;
            defensa2 = (int) (Math.random() * 10) + 5;

            String s = "Los stats de " + nombre1 + " son:";
            s += "\n\tvida: " + vida1;
            s += "\n\tataque: " + ataque1;
            s += "\n\tdefensa: " + defensa1;
            System.out.println(s);

            s = "Los stats de " + nombre2 + " son:";
            s += "\n\tvida: " + vida2;
            s += "\n\tataque: " + ataque2;
            s += "\n\tdefensa: " + defensa2;
            System.out.println(s);

            if (ataque1 > defensa2) {
                vida2 = vida2 - (ataque1 - defensa2);
                if (vida2 <= 0) {
                    vida2 = 0;
                    System.out.println("GRRR..." + nombre2 + " PERDER COMBATE...BSSSS");
                }
            }
            if (ataque2 > defensa1) {
                vida1 = vida1 - (ataque2 - defensa1);
                if (vida1 <= 0) {
                    vida1 = 0;
                    System.out.println("GRRR..." + nombre1 + " PERDER COMBATE...BSSSS");
                }
            }
        }

        if(vida1 > vida2){
            System.out.println(nombre1+" se alza con la victoria");
        } else if (vida1 < vida2) {
            System.out.println(nombre2+" se alza con la victoria");
        } else {
            System.out.println("Ha sido un combate con empate");
        }
    }

}

Como puedes ver, todo está en una única clase y un único método. Esto dificulta la lectura, el mantenimiento y la reutilización del código.

Objetivo de la modularización

La tarea consiste en:

  • Crear una clase XXX (elegir un nombre coherente) que represente a cada personaje del combate.
  • Crear métodos dentro de la clase para acciones concretas, por ejemplo: decirEdad(), cantar(int tiempo), etc.
  • Recordad, dividir el código en métodos pequeños y significativos para que cada parte tenga una única responsabilidad.
  • Elegir nombres claros y descriptivos para clases y métodos.
