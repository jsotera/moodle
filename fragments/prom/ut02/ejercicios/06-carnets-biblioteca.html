2.6 Carnets de biblioteca y elementos estáticos

Trabaja con un contador compartido por toda una clase utilizando static.

Proyecto base

Descarga el proyecto Maven base y ábrelo con IntelliJ IDEA. El proyecto contiene las clases Persona y CarnetBiblioteca documentadas con Javadoc, además de una clase Main preparada para completar la actividad.

Descargar proyecto base

Objetivo

El objetivo es diferenciar entre atributos de instancia y atributos de clase. Cada carnet tiene su propio numero, titular y estado activo, pero todos comparten el contador siguienteNumero.

No debes modificar las clases del paquete modelo. Toda la lógica de prueba debe escribirse en el método main, sin bucles ni condicionales.

Reglas del modelo

  • Una Persona tiene nombre y un carnet de biblioteca.
  • Un CarnetBiblioteca tiene número, titular y estado activo.
  • El número del carnet se asigna automáticamente al construirlo.
  • El atributo estático siguienteNumero pertenece a la clase, no a cada carnet.
  • El método estático consultarSiguienteNumero se invoca desde la clase, no desde un objeto concreto.

Enunciado

Crea una aplicación de prueba con las siguientes condiciones:

  • Consulta y muestra el siguiente número de carnet antes de crear ningún carnet.
  • Crea al menos 3 personas.
  • Crea un carnet para cada persona utilizando el constructor que recibe una Persona.
  • Muestra la información de cada persona y de cada carnet.
  • Consulta de nuevo el siguiente número de carnet.
  • Desactiva uno de los carnets y comprueba que los demás siguen activos.
  • Crea una cuarta persona y un nuevo carnet al final.
  • Comprueba que el nuevo carnet continúa la numeración anterior.

La idea importante

No existe un contador distinto para cada carnet. El contador siguienteNumero es compartido por toda la clase CarnetBiblioteca.

Por eso, cuando creas un carnet nuevo, cambia el valor que verá cualquier llamada posterior a CarnetBiblioteca.consultarSiguienteNumero().

Pruebas avanzadas

  • Consulta CarnetBiblioteca.consultarSiguienteNumero() antes y después de cada constructor.
  • Crea un carnet sin titular y asígnale después una persona con setTitular.
  • Utiliza CarnetBiblioteca.reiniciarSiguienteNumero al principio del programa y observa cómo cambia la numeración.

Salida esperada

La salida puede variar según los nombres que utilices, pero debería mostrar una numeración progresiva:

Siguiente numero antes de crear carnets: 1000
CarnetBiblioteca{numero=1000, titular=Ane, activo=true}
CarnetBiblioteca{numero=1001, titular=Markel, activo=true}
CarnetBiblioteca{numero=1002, titular=June, activo=true}
Siguiente numero despues de crear carnets: 1003

Pistas

  • Los métodos estáticos se llaman desde el nombre de la clase.
  • Los métodos de instancia se llaman desde un objeto concreto.
  • No necesitas usar if, for ni pedir datos por teclado.
  • Usa varios System.out.println para observar cómo cambia el contador compartido.
