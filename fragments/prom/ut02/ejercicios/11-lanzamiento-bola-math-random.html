2.11 Lanzamiento de bola con Math y Random

Crea una simulación sencilla en un único eje para practicar Random, métodos estáticos de Math y expresiones booleanas.

Objetivo

El objetivo es simular una competición de lanzamiento de bola en línea recta. Habrá una diana colocada en una posición aleatoria y varias personas lanzarán su bola intentando quedarse lo más cerca posible.

Todo el ejercicio debe resolverse en el método main. No debes crear clases propias, ni utilizar if, for, while ni pedir datos por teclado.

Métodos necesarios

Clase Método o uso Para qué lo usarás
Random new Random() Crear el generador de números aleatorios.
Random nextInt(limite) Generar posiciones aleatorias para la diana y los lanzamientos.
Math Math.abs(valor) Calcular la distancia entre un lanzamiento y la diana sin importar si queda antes o después.
Math Math.min(valor1, valor2) Obtener la distancia más pequeña o el lanzamiento más corto.
Math Math.max(valor1, valor2) Obtener la distancia más grande o el lanzamiento más largo.

Enunciado

Crea una aplicación de prueba con las siguientes condiciones:

  • Crea un proyecto llamado LanzamientoBola.
  • Todo el código debe estar dentro del método main.
  • Genera aleatoriamente la posición de una diana en una línea de metros.
  • Genera aleatoriamente el lanzamiento de tres participantes.
  • Calcula la distancia de cada lanzamiento respecto a la diana.
  • Calcula cuál es la distancia ganadora.
  • Calcula cuál es la distancia más lejana.
  • Crea variables booleanas para saber si gana cada participante.
  • Crea variables booleanas para saber si cada participante ha sido el más lejano.
  • Muestra todos los datos por consola de forma ordenada.

Datos mínimos

Como mínimo, tu programa debe manejar estos datos:

  • Una variable para la posición de la diana.
  • Una variable para el lanzamiento de cada participante.
  • Una variable para la distancia de cada participante a la diana.
  • Una variable para la distancia ganadora.
  • Una variable para la distancia más lejana.
  • Variables booleanas para indicar quién gana.

Condiciones

  • No utilices if.
  • No utilices bucles.
  • No pidas datos por teclado.
  • No crees clases propias.
  • Utiliza expresiones booleanas para mostrar si una persona gana o no.
  • Ten en cuenta que puede haber empates.

Pruebas avanzadas

  • Añade un cuarto participante.
  • Haz que la diana esté entre los metros 50 y 150.
  • Haz que los lanzamientos estén entre los metros 0 y 200.
  • Calcula el lanzamiento más corto y el lanzamiento más largo.
  • Calcula el rango total entre el lanzamiento más corto y el más largo.

Salida esperada

La salida cambiará en cada ejecución porque los datos son aleatorios, pero debe tener un formato similar a este:

La diana esta en el metro: 63

Ane lanza hasta el metro 70. Distancia: 7
Markel lanza hasta el metro 42. Distancia: 21
June lanza hasta el metro 65. Distancia: 2

Distancia ganadora: 2
Distancia mas lejana: 21

Gana Ane: false
Gana Markel: false
Gana June: true

Nombre del proyecto del ejercicio: LanzamientoBola
