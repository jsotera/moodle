2.10 Máquina expendedora, Random y static

Trabaja con una simulación de ventas donde varias máquinas comparten estadísticas globales mediante elementos static y cada venta puede fallar utilizando Random.

Proyecto base

Descarga el proyecto Maven base y ábrelo con IntelliJ IDEA. El proyecto contiene las clases Producto y MaquinaExpendedora documentadas con Javadoc, además de una clase Main preparada para completar la actividad.

Descargar proyecto base

Objetivo

El objetivo es combinar objetos normales con datos compartidos por toda una clase. Cada producto tiene su propio precio y stock, cada máquina tiene su ubicación y productos, pero todas las máquinas comparten la misma caja global, las ventas globales y la probabilidad de fallo.

En el Main no necesitas usar bucles ni condicionales. Solo debes crear objetos, invocar constructores, llamar a métodos de instancia y llamar a métodos estáticos.

Reglas del modelo

  • Un Producto tiene nombre, precio en céntimos y stock.
  • Una MaquinaExpendedora tiene ubicación y hasta tres productos.
  • La caja global y el número total de ventas son estáticos: pertenecen a la clase, no a una máquina concreta.
  • La probabilidad de fallo también es estática y afecta a todas las máquinas.
  • Cada venta utiliza Random para decidir si la máquina falla.
  • Si la venta falla, no se reduce el stock y no aumenta la caja global.
  • Si la venta funciona, se reduce el stock del producto, aumenta la caja global y aumenta el contador de ventas globales.

Enunciado

Crea una aplicación de prueba con las siguientes condiciones:

  • Reinicia las estadísticas globales de la clase MaquinaExpendedora.
  • Configura una probabilidad de fallo inicial.
  • Crea al menos 3 productos con distinto precio y stock.
  • Crea al menos 2 máquinas expendedoras con ubicaciones diferentes.
  • Coloca productos en las máquinas.
  • Realiza varias ventas invocando métodos de instancia.
  • Consulta la caja global y las ventas globales invocando métodos estáticos.
  • Cambia la probabilidad de fallo y realiza nuevas ventas.
  • Muestra la información de las máquinas y productos para observar cómo cambia el stock.

La idea importante

Si dos máquinas venden productos diferentes, ambas suman dinero a la misma caja global. Esa caja no está dentro de cada objeto máquina: pertenece a la clase MaquinaExpendedora.

Además, si modificas la probabilidad de fallo desde la clase, todas las máquinas pasan a usar ese nuevo valor.

Pruebas avanzadas

  • Configura la probabilidad de fallo a 0 y comprueba que las ventas siempre pueden funcionar si hay stock.
  • Configura la probabilidad de fallo a 100 y comprueba que ninguna venta se completa.
  • Agota el stock de un producto vendiéndolo varias veces.
  • Crea una segunda máquina y comprueba que sus ventas también aumentan la caja global.

Salida esperada

La salida puede variar porque algunas ventas dependen de Random, pero debería mostrar mensajes similares a estos:

Venta correcta en Entrada: Agua.
La maquina de Pasillo ha fallado al vender Cafe.
Venta correcta en Entrada: Galletas.
Caja global: 270
Ventas globales: 2

Pistas

  • Los métodos estáticos se invocan desde MaquinaExpendedora.
  • Los métodos de venta se invocan desde una máquina concreta.
  • No necesitas usar if, for ni pedir datos por teclado.
  • Ejecuta el programa varias veces para observar el efecto de Random.

Nombre del proyecto del ejercicio: MaquinaExpendedora
