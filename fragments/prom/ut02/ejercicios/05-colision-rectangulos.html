2.5 Colisión de rectángulos

Crea dos objetos de tipo Rectangulo y analiza desde Main si ocupan una zona común.

Proyecto base

Descarga el proyecto Maven base y ábrelo con IntelliJ IDEA. El proyecto contiene la clase Rectangulo documentada con Javadoc, además de una clase Main preparada para completar la actividad.

Descargar proyecto base

Objetivo

El objetivo es practicar la creación de objetos, el acceso a sus propiedades mediante getters y el uso de expresiones booleanas para resolver un problema geométrico sencillo.

No debes modificar la clase Rectangulo. Toda la lógica para comprobar la colisión debe escribirse en el método main.

Reglas del modelo

  • Un Rectangulo tiene coordenadas x e y.
  • También tiene altura y anchura.
  • Las coordenadas representan la esquina superior izquierda del rectángulo.
  • La colisión no la calcula la clase Rectangulo; debe calcularse desde Main.

Enunciado

Crea una aplicación de prueba con las siguientes condiciones:

  • Crea dos rectángulos con coordenadas, altura y anchura diferentes.
  • Muestra por consola la información de ambos rectángulos.
  • Calcula el borde izquierdo, derecho, superior e inferior de cada rectángulo.
  • Comprueba si los dos rectángulos colisionan.
  • Muestra un mensaje indicando si existe colisión o no.

Pista de razonamiento

Dos rectángulos no colisionan si uno está completamente a la izquierda, a la derecha, por encima o por debajo del otro.

derecha1 = x1 + anchura1
abajo1 = y1 + altura1

derecha2 = x2 + anchura2
abajo2 = y2 + altura2

A partir de esos límites, puedes construir una expresión booleana para saber si hay colisión.

Pruebas avanzadas

  • Prueba con rectángulos que claramente colisionen.
  • Prueba con rectángulos separados horizontalmente.
  • Prueba con rectángulos separados verticalmente.
  • Prueba con rectángulos que solo se toquen por un borde y decide si quieres considerarlo colisión o no.

Salida esperada

La salida puede variar según los valores que utilices, pero debería ser similar a esta:

Rectangulo{x=10, y=10, altura=40, anchura=80}
Rectangulo{x=50, y=20, altura=30, anchura=60}

Los rectangulos colisionan.
