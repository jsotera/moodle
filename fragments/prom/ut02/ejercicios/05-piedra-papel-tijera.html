2.5 Piedra, papel o tijera

Desarrolla una simulación sencilla de piedra, papel o tijera utilizando dos clases dadas: Persona y Juego.

Proyecto base

Descarga el proyecto Maven base y ábrelo con IntelliJ IDEA. El proyecto contiene las clases Persona y Juego documentadas con Javadoc, además de una clase Main preparada para completar la actividad.

Descargar proyecto base

Objetivo

El objetivo es practicar el uso de objetos relacionados de una forma más sencilla: dos personas participan en un juego, y la clase Juego se encarga de asignar jugadas, decidir el resultado y actualizar los marcadores.

No debes modificar las clases del paquete modelo. Toda la lógica de prueba debe escribirse en el método main.

Reglas del modelo

  • Una Persona tiene nombre, jugada actual, partidas ganadas, partidas perdidas y partidas empatadas.
  • Un Juego tiene dos personas participantes.
  • Cada vez que se llama a jugar, el juego asigna automáticamente una jugada a cada persona.
  • La clase Juego decide quién gana y actualiza los contadores de ambas personas.
  • Desde Main no debes modificar directamente los marcadores.

Enunciado

Crea una aplicación de prueba con las siguientes condiciones:

  • Crea dos personas con nombres distintos.
  • Crea una instancia de Juego con esas dos personas.
  • Ejecuta varias partidas llamando al método jugar.
  • Muestra el marcador utilizando el método obtenerMarcador.
  • Muestra también por consola las dos variables originales de tipo Persona.

La idea importante

La clase Juego modifica los contadores de las personas que recibió en el constructor. Cuando después imprimas las variables originales de Main, verás esos cambios porque son los mismos objetos.

Pruebas avanzadas

  • Ejecuta 10 partidas usando un bucle for.
  • Crea un segundo juego reutilizando una de las personas anteriores contra una persona nueva.
  • Comprueba si el marcador de la persona reutilizada conserva las partidas anteriores.

Salida esperada

La salida cambiará porque las jugadas son aleatorias, pero debería mostrar mensajes similares a estos:

Ane juega piedra.
Markel juega tijera.
Gana Ane.

Ane juega papel.
Markel juega papel.
La partida termina en empate.

Persona{nombre='Ane', jugadaActual='papel', ganadas=1, perdidas=0, empatadas=1}
Persona{nombre='Markel', jugadaActual='papel', ganadas=0, perdidas=1, empatadas=1}

Pistas

  • Lee el Javadoc de jugar y obtenerMarcador.
  • No necesitas pedir datos por teclado.
  • Recuerda que cada llamada a jugar representa una partida completa.
  • Observa cómo cambian los objetos Persona aunque los cambios los haga la clase Juego.
