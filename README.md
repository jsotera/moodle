# Teoría de Programación en Java

Material didáctico de introducción a la programación en Java, organizado en bloques y publicado mediante GitHub Pages.

## Acceso al temario

Puedes consultar la versión publicada en:

### [Abrir el temario de Programación en Java](https://jsotera.github.io/teoria/)

## Contenidos

El temario está organizado en los siguientes bloques:

1. **Fundamentos de Java**
   - Estructura básica de un programa.
   - Método `main`.
   - Salida de información por pantalla.
   - Compilación, bytecode y JVM.

2. **Variables, tipos de datos y constantes**
   - Declaración, inicialización y modificación de variables.
   - Tipos primitivos y `String`.
   - Literales y constantes.
   - Reglas para nombrar variables.

3. **Operadores y expresiones**
   - Operadores aritméticos.
   - Operadores relacionales y lógicos.
   - Operadores de asignación.
   - División entera, módulo y prioridad de operadores.

4. **Conversiones de tipo y documentación**
   - Conversión implícita y casting.
   - Casting aplicado a divisiones.
   - Comentarios de una línea y de varias líneas.
   - Javadoc y legibilidad del código.

## Ejecución local

No es necesario instalar dependencias. Puedes descargar el repositorio y abrir `index.html` directamente en un navegador.

También puedes utilizar un servidor local:

```bash
python3 -m http.server 8000
```

Después, abre:

```text
http://localhost:8000
```

## Publicación

El contenido se publica automáticamente con GitHub Pages desde la rama configurada en el repositorio.
