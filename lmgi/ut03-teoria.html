    3.1 Introducción a HTML

    HTML es el lenguaje de marcas que utilizamos para estructurar el contenido de una página web.

    Además de esta documentación de clase, puedes consultar la introducción completa de HTML en W3Schools HTML Introduction.

    ¿Qué es HTML?

    HTML significa HyperText Markup Language, es decir, lenguaje de marcado de hipertexto.

    No es un lenguaje de programación como Java. HTML no se utiliza para definir algoritmos, condiciones o bucles, sino para indicar al navegador qué elementos forman una página: títulos, párrafos, enlaces, imágenes, listas, tablas, formularios, etc.

    La idea principal es sencilla: escribimos texto rodeado de etiquetas, y esas etiquetas describen el significado o la función de cada parte del contenido.

    Etiquetas y elementos

    Una etiqueta HTML se escribe utilizando los símbolos < y >. Muchas etiquetas tienen una etiqueta de apertura y otra de cierre:

    <p>Este es un párrafo.</p>

    Resultado visual:

    Este es un párrafo.

    En ese ejemplo:

    • <p> es la etiqueta de apertura.
    • Este es un párrafo. es el contenido.
    • </p> es la etiqueta de cierre.

    Al conjunto formado por apertura, contenido y cierre lo llamamos elemento HTML.

    Documento HTML mínimo

    Una página HTML sencilla suele tener esta estructura:

    <!DOCTYPE html>
<html>
  <head>
    <title>Título de la página</title>
  </head>
  <body>
    <h1>Mi primer encabezado</h1>
    <p>Mi primer párrafo.</p>
  </body>
</html>

    Resultado visual del contenido del body:

    Mi primer encabezado

    Mi primer párrafo.

    Esta estructura será nuestra base durante toda la unidad. Más adelante iremos añadiendo nuevas etiquetas y atributos.

    Partes principales de la estructura

    Elemento Función
    <!DOCTYPE html> Indica al navegador que el documento usa HTML moderno.
    <html> Es el elemento raíz del documento HTML.
    <head> Contiene información sobre la página, como el título o la codificación.
    <title> Define el título que aparece en la pestaña del navegador.
    <body> Contiene el contenido visible de la página.
    <h1> Representa un encabezado principal.
    <p> Representa un párrafo de texto.

    Lo que interpreta el navegador

    El navegador no muestra las etiquetas tal cual. Lee el documento HTML, interpreta su estructura y representa el contenido de forma visual.

    Por ejemplo, este código:

    <h1>Bienvenida</h1>
<p>Esta es mi primera página web.</p>

    Resultado visual:

    Bienvenida

    Esta es mi primera página web.

    no se muestra como texto con símbolos < y >, sino como un título grande y un párrafo debajo.

    HTML no decide el aspecto final completo

    HTML describe la estructura y el significado del contenido. El aspecto visual, como colores, tamaños, márgenes o disposición, se trabajará principalmente con CSS.

    Por eso, en esta unidad nos centraremos primero en escribir documentos HTML correctos y bien organizados. Más adelante veremos cómo darles estilo.

    3.2 Etiquetas básicas de texto

    HTML permite organizar el contenido de una página utilizando etiquetas con significado.

    Títulos: h1, h2, h3...

    Las etiquetas de título se utilizan para organizar la información de una página en niveles.

    HTML ofrece seis niveles de encabezado: desde <h1>, que representa el título principal, hasta <h6>, que representa un título de menor importancia.

    <h1>Lenguajes de marcas</h1>
<h2>HTML</h2>
<h3>Etiquetas básicas</h3>

    Resultado visual:

    Lenguajes de marcas

    HTML

    Etiquetas básicas

    Lo importante no es solo que se vean más grandes o más pequeños, sino que indican la estructura jerárquica del contenido.

    Párrafos: p

    La etiqueta <p> se utiliza para escribir párrafos de texto.

    <p>HTML se utiliza para definir la estructura de una página web.</p>
<p>Cada etiqueta ayuda al navegador a interpretar el contenido.</p>

    Resultado visual:

    HTML se utiliza para definir la estructura de una página web.

    Cada etiqueta ayuda al navegador a interpretar el contenido.

    Cuando queremos escribir texto normal dentro de una página, lo habitual es agruparlo en párrafos.

    Texto en línea: span

    La etiqueta <span> se utiliza para marcar una parte pequeña de un texto sin crear un bloque nuevo.

    <p>El lenguaje <span>HTML</span> se interpreta en el navegador.</p>

    Resultado visual:

    El lenguaje HTML se interpreta en el navegador.

    Por sí sola, <span> no cambia visualmente el texto. Suele utilizarse cuando más adelante queremos aplicar estilos o identificar una parte concreta del contenido.

    Negrita e importancia: b y strong

    La etiqueta <b> muestra el texto en negrita, pero no añade un significado especial al contenido.

    <p>Este texto contiene una palabra en <b>negrita</b>.</p>

    Resultado visual:

    Este texto contiene una palabra en negrita.

    La etiqueta <strong> también suele mostrarse en negrita, pero indica que esa parte del texto tiene importancia.

    <p><strong>Importante:</strong> guarda siempre una copia del archivo.</p>

    Resultado visual:

    Importante: guarda siempre una copia del archivo.

    Como norma general, si queremos destacar algo porque es importante, es mejor utilizar <strong>.

    Cursiva y énfasis: i y em

    La etiqueta <i> muestra el texto en cursiva, normalmente con un sentido visual.

    <p>La palabra <i>browser</i> significa navegador.</p>

    Resultado visual:

    La palabra browser significa navegador.

    La etiqueta <em> también suele mostrarse en cursiva, pero indica que queremos dar énfasis a una parte del texto.

    <p>No debes borrar <em>ese</em> archivo.</p>

    Resultado visual:

    No debes borrar ese archivo.

    La diferencia es parecida a la de <b> y <strong>: una etiqueta se centra más en el aspecto visual y la otra en el significado.

    Código: code y pre

    La etiqueta <code> se utiliza para marcar fragmentos de código dentro de un texto.

    <p>La etiqueta <code>&lt;p&gt;</code> sirve para crear párrafos.</p>

    Resultado visual:

    La etiqueta <p> sirve para crear párrafos.

    Cuando queremos mostrar varias líneas de código, podemos combinar <pre> y <code>. La etiqueta <pre> conserva los saltos de línea y los espacios.

    <pre><code>
&lt;h1&gt;Título&lt;/h1&gt;
&lt;p&gt;Texto de ejemplo&lt;/p&gt;
</code></pre>

    Saltos y separadores: br y hr

    La etiqueta <br> inserta un salto de línea. Es una etiqueta vacía, por lo que no necesita etiqueta de cierre.

    <p>Primera línea<br>Segunda línea</p>

    Resultado visual:

    Primera línea
    Segunda línea

    La etiqueta <hr> crea una separación temática entre contenidos.

    <h2>Tema 1</h2>
<p>Contenido del primer tema.</p>
<hr>
<h2>Tema 2</h2>
<p>Contenido del segundo tema.</p>

    Resultado visual:

    Tema 1

    Contenido del primer tema.

    Tema 2

    Contenido del segundo tema.

    Conviene no abusar de estas etiquetas: muchas veces la separación visual se resolverá más adelante con CSS.

    Listas: ul, ol y li

    HTML permite crear listas no ordenadas y listas ordenadas.

    Las listas no ordenadas utilizan <ul> y cada elemento se escribe con <li>:

    <ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

    Resultado visual:

    • HTML
    • CSS
    • JavaScript

    Las listas ordenadas utilizan <ol>:

    <ol>
  <li>Crear el archivo HTML</li>
  <li>Escribir la estructura básica</li>
  <li>Abrirlo en el navegador</li>
</ol>

    Resultado visual:

    1. Crear el archivo HTML
    2. Escribir la estructura básica
    3. Abrirlo en el navegador

    Enlaces: a

    La etiqueta <a> crea un enlace o hipervínculo. Al pulsarlo, el navegador nos lleva al destino indicado en el atributo href. El texto entre la apertura y el cierre es lo que verá la persona que visita la página.

    <a href="https://www.w3schools.com/">Visitar W3Schools</a>

    Resultado visual:

    Visitar W3Schools

    El destino puede ser una dirección completa de otra web o una ruta relativa a un archivo de nuestro propio sitio:

    <a href="contacto.html">Contactar</a>
<a href="paginas/horario.html">Consultar el horario</a>
<a href="../index.html">Volver al inicio</a>
    • contacto.html: busca el archivo en la misma carpeta que la página actual.
    • paginas/horario.html: entra en la subcarpeta paginas.
    • ../index.html: sube una carpeta y busca allí index.html.

    Por defecto, el enlace se abre en la pestaña actual. Con target="_blank" solicitamos que se abra en una nueva pestaña o ventana, según la configuración del navegador. En estos enlaces añadiremos rel="noopener noreferrer" para impedir que la página de destino acceda a la ventana de origen y evitar enviarle la dirección de procedencia.

    <a href="https://www.w3schools.com/" target="_blank" rel="noopener noreferrer">
  Consultar W3Schools (abre en otra pestaña)
</a>

    Resultado visual:

    Consultar W3Schools (abre en otra pestaña)
    Enlaces a una sección de la página

    También podemos saltar a un elemento concreto. Primero le asignamos un id único y después usamos ese identificador precedido de # en el enlace:

    <a href="#horario">Ir al horario</a>

<h2 id="horario">Horario de clase</h2>
<p>Las clases comienzan a las 8:00.</p>

    Resultado visual:

    Ir al horario

    Horario de clase

    Las clases comienzan a las 8:00.

    Para ir a una sección de otra página, combinamos ambos destinos: contacto.html#horario. El elemento con ese id debe existir en la página de destino.

    Buena práctica: utiliza textos que expliquen el destino, como «Consultar el horario», en lugar de un «Haz clic aquí» sin contexto.

    Imágenes: img

    La etiqueta <img> se utiliza para mostrar imágenes dentro de una página HTML.

    A diferencia de otras etiquetas, <img> es una etiqueta vacía: no tiene contenido entre una apertura y un cierre. La información importante se indica mediante atributos.

    <img src="paisaje.jpg" alt="Paisaje de montaña">

    Resultado visual:

    Los dos atributos más importantes son:

    • src: indica la ruta o dirección de la imagen que queremos mostrar.
    • alt: describe la imagen si no se puede cargar o si la persona utiliza un lector de pantalla.

    El atributo alt no es un adorno: ayuda a que la página sea más accesible y comprensible.

    <img src="logo.png" alt="Logo del centro" width="180">

    Los atributos width y height permiten indicar el tamaño de la imagen. Más adelante veremos que normalmente controlaremos mejor el tamaño con CSS.

    Atributos útiles en estas etiquetas

    Algunas etiquetas admiten atributos que modifican o completan su comportamiento. En esta unidad todavía no vamos a usar estilos CSS propios, pero sí conviene conocer algunos atributos básicos.

    Atributo Dónde se usa Para qué sirve Ejemplo
    href <a> Indica la dirección, el archivo o la sección de destino del enlace. <a href="contacto.html">Contacto</a>
    target <a> Indica dónde se abre el destino: _self en la pestaña actual (valor predeterminado) y _blank en una nueva pestaña o ventana. <a href="contacto.html" target="_blank" rel="noopener noreferrer">Contacto</a>
    rel <a> Describe la relación con el destino. Utilizaremos noopener noreferrer al abrir otra pestaña. rel="noopener noreferrer"
    start <ol> Indica desde qué número comienza una lista ordenada. <ol start="4">
    type <ol> Cambia el tipo de numeración: números, letras o números romanos. <ol type="A">
    reversed <ol> Muestra la numeración de la lista en orden descendente. <ol reversed>
    id Cualquier etiqueta Identifica un elemento concreto de forma única dentro de la página. <h2 id="listas">
    class Cualquier etiqueta Agrupa elementos para poder tratarlos de forma común más adelante. <span class="importante">
    title Cualquier etiqueta Añade información adicional que el navegador puede mostrar al pasar el ratón. <p title="Texto de ayuda">
    src <img> Indica la ruta o URL de la imagen que se va a mostrar. <img src="foto.jpg">
    alt <img> Describe la imagen cuando no se puede ver o no se carga correctamente. <img alt="Foto de perfil">
    width <img> Indica la anchura de la imagen. <img width="200">
    height <img> Indica la altura de la imagen. <img height="120">

    Por ejemplo, podemos hacer que una lista ordenada empiece en el número 4:

    <ol start="4">
  <li>Revisar el código</li>
  <li>Guardar el archivo</li>
  <li>Abrir la página en el navegador</li>
</ol>

    Resultado visual:

    1. Revisar el código
    2. Guardar el archivo
    3. Abrir la página en el navegador

    También podemos cambiar el tipo de numeración:

    <ol type="A">
  <li>Primera opción</li>
  <li>Segunda opción</li>
  <li>Tercera opción</li>
</ol>

    Resultado visual:

    1. Primera opción
    2. Segunda opción
    3. Tercera opción

    Y, si usamos reversed, la numeración aparece en sentido descendente:

    <ol reversed>
  <li>Último paso</li>
  <li>Paso intermedio</li>
  <li>Primer paso</li>
</ol>

    Resultado visual:

    1. Último paso
    2. Paso intermedio
    3. Primer paso

    <img src="logo.png" alt="Logo de ejemplo" width="180">

    <h2>Lenguajes que veremos</h2>
    <ul>
      <li>HTML</li>
      <li>CSS</li>
      <li>JavaScript</li>
    </ul>
  </body>
</html>

    Resultado visual del contenido del body:

    3.3 Tablas en HTML

    Las tablas permiten organizar información en filas y columnas cuando los datos tienen una estructura tabular.

    Estructura básica de una tabla

    Una tabla HTML se crea con la etiqueta <table>. Dentro de ella se definen filas con <tr> y celdas con <td>.

    <table>
  <tr>
    <td>Nombre</td>
    <td>Edad</td>
  </tr>
  <tr>
    <td>Ane</td>
    <td>18</td>
  </tr>
</table>

    Resultado visual:

    Nombre Edad
    Ane 18

    En este ejemplo hay dos filas. Cada fila contiene dos celdas.

    Etiquetas principales

    Las etiquetas más habituales para construir tablas son las siguientes:

    Etiqueta Uso Ejemplo
    <table> Define la tabla completa. <table>...</table>
    <tr> Define una fila. <tr>...</tr>
    <td> Define una celda normal. <td>Dato</td>
    <th> Define una celda de cabecera. <th>Nombre</th>
    <caption> Añade un título descriptivo a la tabla. <caption>Listado</caption>

    Mostrar las líneas de la tabla

    Por defecto, una tabla HTML puede verse sin líneas entre filas y columnas. Para trabajar en clase, nos interesa que esas líneas se vean claramente.

    Antiguamente era habitual usar atributos HTML como border directamente en la etiqueta <table>, pero actualmente es mejor separar la estructura de la apariencia visual. La estructura la escribimos con HTML y el aspecto visual lo definimos con CSS.

    De momento no hace falta entender todos los detalles de este CSS. Lo estudiaremos con calma en la siguiente unidad. Por ahora, podéis copiar este fragmento dentro de la cabecera del documento, es decir, dentro de <head>:

    <head>
  <meta charset="UTF-8">
  <title>Tabla con bordes</title>
  <style>
    table {
      border-collapse: collapse;
    }

    th,
    td {
      border: 1px solid black;
      padding: 8px;
    }
  </style>
</head>

    Con este fragmento, las celdas de la tabla tendrán borde y algo de espacio interior para que los datos se lean mejor.

    Resultado visual con ese CSS aplicado:

    Módulo Horas
    Lenguaje de marcas 132
    Aunque aquí veas estilos escritos dentro del ejemplo, en esta unidad lo importante sigue siendo construir bien la tabla con HTML. El CSS lo usaremos solo como ayuda visual.

    Cabeceras con th

    Cuando una celda representa el título de una columna o de una fila, es mejor usar <th> en lugar de <td>.

    <table>
  <tr>
    <th>Módulo</th>
    <th>Horas</th>
  </tr>
  <tr>
    <td>Lenguaje de marcas</td>
    <td>132</td>
  </tr>
</table>

    Resultado visual:

    Módulo Horas
    Lenguaje de marcas 132

    Visualmente, muchos navegadores muestran <th> en negrita y centrado, pero su valor principal es que indica que esa celda funciona como cabecera.

    thead, tbody y tfoot

    En tablas algo más completas, podemos separar la cabecera, el cuerpo y el pie de la tabla.

    <table>
  <caption>Notas de la evaluación</caption>
  <thead>
    <tr>
      <th>Alumno/a</th>
      <th>Prueba 1</th>
      <th>Prueba 2</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>June</td>
      <td>8</td>
      <td>7</td>
    </tr>
    <tr>
      <td>Iker</td>
      <td>6</td>
      <td>9</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th>Media</th>
      <td>7</td>
      <td>8</td>
    </tr>
  </tfoot>
</table>

    Resultado visual:

    Notas de la evaluación
    Alumno/a Prueba 1 Prueba 2
    June 8 7
    Iker 6 9
    Media 7 8

    Estas etiquetas no son obligatorias en tablas pequeñas, pero ayudan a que el documento sea más claro y fácil de interpretar.

    Combinar columnas con colspan

    El atributo colspan permite que una celda ocupe varias columnas.

    <table>
  <tr>
    <th colspan="3">Horario del lunes</th>
  </tr>
  <tr>
    <th>Hora</th>
    <th>Módulo</th>
    <th>Aula</th>
  </tr>
  <tr>
    <td>08:15</td>
    <td>Lenguaje de marcas</td>
    <td>Aula 204</td>
  </tr>
</table>

    Resultado visual:

    Horario del lunes
    Hora Módulo Aula
    08:15 Lenguaje de marcas Aula 204

    En este caso, la primera celda ocupa el espacio de tres columnas.

    Combinar filas con rowspan

    El atributo rowspan permite que una celda ocupe varias filas.

    <table>
  <tr>
    <th>Turno</th>
    <th>Módulo</th>
    <th>Profesor/a</th>
  </tr>
  <tr>
    <td rowspan="2">Mañana</td>
    <td>HTML</td>
    <td>Ane</td>
  </tr>
  <tr>
    <td>CSS</td>
    <td>Ane</td>
  </tr>
</table>

    Resultado visual:

    Turno Módulo Profesor/a
    Mañana HTML Ane
    CSS Ane

    La celda Mañana ocupa dos filas, por eso en la segunda fila ya no se escribe otra celda para el turno.

    colspan y rowspan juntos

    Los atributos colspan y rowspan pueden combinarse, pero hay que tener cuidado para que todas las filas mantengan una estructura coherente.

    <table>
  <tr>
    <th rowspan="2">Alumno/a</th>
    <th colspan="2">Evaluación 1</th>
    <th colspan="2">Evaluación 2</th>
  </tr>
  <tr>
    <th>Teoría</th>
    <th>Práctica</th>
    <th>Teoría</th>
    <th>Práctica</th>
  </tr>
  <tr>
    <td>Nora</td>
    <td>7</td>
    <td>8</td>
    <td>6</td>
    <td>9</td>
  </tr>
</table>

    Resultado visual:

    Alumno/a Evaluación 1 Evaluación 2
    Teoría Práctica Teoría Práctica
    Nora 7 8 6 9

    Una buena forma de construir este tipo de tablas es dibujar primero la tabla en papel y después convertir cada fila a HTML.

    Otros atributos útiles

    Además de colspan y rowspan, en tablas pueden aparecer otros atributos generales de HTML.

    Atributo Dónde puede aparecer Uso
    id Cualquier etiqueta Identifica un elemento concreto de forma única.
    class Cualquier etiqueta Permite agrupar elementos para aplicar estilos o comportamiento.
    title Cualquier etiqueta Añade información adicional que puede mostrarse al pasar el ratón.
    scope <th> Indica si una cabecera corresponde a una columna, una fila o un grupo. 
    <table class="table">
  <tr>
    <th scope="col">Producto</th>
    <th scope="col">Precio</th>
  </tr>
  <tr>
    <td>Teclado</td>
    <td>25 €</td>
  </tr>
</table>

    Resultado visual:

    Producto Precio
    Teclado 25 €

    Tablas para datos, no para maquetar

    Las tablas deben utilizarse cuando la información realmente tiene forma de tabla: listados, horarios, notas, comparativas, resultados, etc.

    No es recomendable usar tablas para colocar visualmente partes de una página. Para organizar el diseño de una web se utilizarán otras técnicas con HTML y CSS.

    3.4 Formularios en HTML

    Los formularios permiten recoger información: escribir un nombre, elegir una opción, marcar preferencias o adjuntar un archivo.

    El formulario: form

    La etiqueta <form> agrupa los controles que forman un formulario. Cada control permite introducir o seleccionar un dato. Un botón de envío solicita al navegador que compruebe los campos y envíe los datos al destino configurado.

    <form action="/inscripciones" method="post">
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre" required>
  <button type="submit">Inscribirme</button>
</form>

    La ruta /inscripciones es un destino de ejemplo: para que los datos se guarden, debe existir un programa que los reciba y procese. HTML construye el formulario, pero no guarda los datos por sí solo. GitHub Pages publica archivos estáticos; no ejecuta por sí mismo ese programa receptor.

    Atributo de formPara qué sirveEjemplo
    actionDirección a la que se envían los datos. Si se omite, el destino es la página actual.action="/inscripciones"
    methodMétodo de envío. Los más habituales son get y post. El predeterminado es get.method="post"
    enctypeFormato de los datos. El habitual es application/x-www-form-urlencoded. Para enviar archivos con POST se utiliza multipart/form-data.enctype="multipart/form-data"
    autocompleteIndica si se permite al navegador sugerir o completar valores previamente conocidos. Los controles pueden indicar su propia configuración.autocomplete="on"
    targetIndica dónde se abre la respuesta. Por defecto, en la pestaña actual.target="_blank"
    novalidateDesactiva la validación automática del navegador al enviar. Normalmente lo omitiremos para aprovechar las comprobaciones de HTML.<form novalidate>

    No se puede colocar un formulario dentro de otro. Utilizaremos párrafos y grupos de campos para organizar su contenido, sin necesitar CSS por el momento.

    label, for, id, name y value

    La etiqueta <label> escribe el texto que identifica un control. Su atributo for debe coincidir exactamente con el id del control asociado. Al pulsar la etiqueta, el navegador enfoca el campo o activa la casilla correspondiente.

    <label for="nombre-alumno">Nombre del alumno o alumna:</label>
<input type="text" id="nombre-alumno" name="nombre" value="Ane">

    Resultado visual:

    ElementoFunciónEn el ejemplo
    label y forProporcionan una etiqueta asociada al control.for="nombre-alumno" apunta al campo.
    idIdentifica el elemento de forma única en todo el documento.id="nombre-alumno"
    nameEs el nombre con el que se envía el dato. No tiene por qué coincidir con el id.name="nombre"
    valueEn un campo de texto, establece su valor inicial. Al enviar se utiliza el valor actual, que la persona puede haber cambiado.Inicialmente se enviaría nombre=Ane.

    Un id no sustituye a name: un campo de datos puede tener etiqueta e identificador y, aun así, no incluirse en el envío si carece de name. Los identificadores deben ser únicos; los nombres pueden repetirse cuando queremos agrupar datos.

    Campos de entrada: input y type

    <input> es una etiqueta vacía: no lleva cierre </input>. Su atributo type determina qué control crea. Si no se indica, el tipo predeterminado es text.

    typeUsoAtributos especialmente útiles
    textTexto en una línea.minlength, maxlength, placeholder
    passwordTexto cuyos caracteres se ocultan visualmente.minlength, autocomplete="new-password"
    emailCorreo con comprobación básica de formato.required, multiple para varios correos separados por comas
    numberValores numéricos.min, max, step
    telTeléfono; puede facilitar un teclado adaptado en móviles. No impone por sí solo un formato de teléfono.pattern, autocomplete="tel"
    urlUna dirección web con comprobación básica de formato.placeholder, required
    searchTexto de búsqueda.placeholder, maxlength
    date, timeFecha o una hora.min, max, step
    datetime-localFecha y hora local, sin zona horaria.min, max
    month, weekMes o semana. Su presentación depende del navegador.min, max
    rangeSelector deslizante para un intervalo numérico.min, max, step, value
    colorSelector de color.value="#336699"
    checkboxCasilla que puede marcarse o desmarcarse.checked, value
    radioUna alternativa dentro de un grupo.name compartido, value, checked
    fileSelección de archivos.accept, multiple
    hiddenDato que se envía sin mostrar un control.name, value
    submit, reset, buttonBotones de envío, restablecimiento o acción.value contiene su texto visible.
     
    <p>
  <label for="correo-ejemplo">Correo:</label>
  <input type="email" id="correo-ejemplo" name="correo"
         placeholder="nombre@ejemplo.com" required>
</p>
<p>
  <label for="edad-ejemplo">Edad:</label>
  <input type="number" id="edad-ejemplo" name="edad" min="16" max="100" step="1">
</p>
<p>
  <label for="fecha-ejemplo">Fecha:</label>
  <input type="date" id="fecha-ejemplo" name="fecha">
</p>

    Resultado visual:

    password solo oculta visualmente los caracteres: no cifra los datos. Para proteger el envío se necesita HTTPS. Tampoco conviene usar number para códigos postales o teléfonos: son identificadores, no cantidades con las que realizar cálculos.

    Atributos de los campos y validación

    El navegador puede comprobar algunos requisitos antes de enviar. Los atributos disponibles dependen del tipo de control: no todos sirven para cualquier etiqueta.

    AtributoSignificadoEjemplo
    requiredExige completar o seleccionar un valor válido antes de enviar.<input type="email" required>
    placeholderPista visible cuando un campo compatible está vacío. No es su valor ni sustituye a la etiqueta.placeholder="Tu nombre"
    minlength, maxlengthLímites de longitud para campos de texto compatibles y textarea.minlength="3" maxlength="30"
    min, maxLímites para números y tipos compatibles de fecha y hora.min="0" max="10"
    stepPaso permitido para números u otros tipos compatibles. En number, el paso predeterminado es 1.step="0.5" o step="any"
    patternPatrón que debe cumplir todo el texto en tipos como text, tel o password.pattern="[0-9]{5}": cinco dígitos
    readonlyImpide editar un campo compatible, pero permite enviar su valor. Se aplica a campos de texto, entre otros, y a textarea; no a select, radios o casillas.<input type="text" name="curso" value="DAW" readonly>
    disabledDeshabilita un control. No se incluye en el envío y no participa en la validación.<select disabled>...</select>
    autocompleteIndica qué dato puede autocompletar el navegador.autocomplete="name" o autocomplete="email"
    sizeAnchura aproximada en caracteres para ciertos campos de texto. En select tiene otro significado: cantidad de opciones visibles.<input type="text" size="15">
     
    <label for="postal-ejemplo">Código postal (cinco dígitos):</label>
<input type="text" id="postal-ejemplo" name="codigoPostal"
       pattern="[0-9]{5}" maxlength="5" placeholder="31001" required>

    El patrón comprueba la forma del texto, no que exista ese código postal. Sin required, un campo con pattern puede dejarse vacío.

    Atributos booleanos: required, disabled, readonly, checked, selected y multiple se activan por estar presentes. Escribir disabled="false" también deshabilita: para desactivarlo hay que quitar el atributo.

    La validación del navegador ayuda a completar el formulario, pero el programa que recibe los datos debe volver a comprobarlos. El tipo email, por ejemplo, no demuestra que la dirección exista.

    Casillas de verificación: checkbox

    Una casilla representa una opción que puede activarse o desactivarse. Varias casillas permiten elegir varias alternativas simultáneamente.

    <p>
  <input type="checkbox" id="interes-html" name="intereses" value="html" checked>
  <label for="interes-html">HTML</label>
</p>
<p>
  <input type="checkbox" id="interes-css" name="intereses" value="css">
  <label for="interes-css">CSS</label>
</p>

    Resultado visual:

    checked marca la opción inicialmente. value indica el dato que se envía si está marcada, no su estado de marcado. Si se eligen ambas, se enviarán dos valores con el mismo nombre: intereses=html e intereses=css.

    Las casillas desmarcadas no se envían. Si se omite value, el valor de una casilla marcada será on. Para exigir aceptar una condición concreta, se puede añadir required a esa casilla.

    A diferencia de los radios, compartir name no impide marcar varias casillas. Además, required en una casilla exige marcar esa casilla concreta; no significa «elige al menos una de este grupo».

    Botones de opción: radio

    Los controles radio sirven para elegir una sola alternativa de un grupo. En un mismo formulario, los que comparten el atributo name pertenecen al mismo grupo.

    <fieldset>
  <legend>Turno preferido</legend>
  <input type="radio" id="turno-manana" name="turno" value="manana" required>
  <label for="turno-manana">Mañana</label>
  <input type="radio" id="turno-tarde" name="turno" value="tarde">
  <label for="turno-tarde">Tarde</label>
</fieldset>

    Resultado visual:

    Turno preferido
    • name es igual en todas las alternativas del grupo.
    • id es diferente en cada alternativa; cada label apunta al suyo.
    • value identifica la alternativa elegida: se enviaría turno=manana o turno=tarde.
    • checked permite seleccionar una alternativa inicialmente. Úsalo como máximo en una opción del grupo.
    • Si algún radio del grupo tiene required, se exige elegir una opción de ese grupo, no necesariamente ese radio.

    Si ponemos nombres diferentes, no se comportarán como alternativas excluyentes. Otro grupo, por ejemplo name="modalidad", será independiente del turno.

    Listas de selección: select, option y optgroup

    <select> crea una lista de selección y cada <option> representa una alternativa. La etiqueta correcta es option, en singular, no options.

    <label for="ciclo-ejemplo">Ciclo:</label>
<select id="ciclo-ejemplo" name="ciclo" required>
  <option value="" selected disabled>Elige un ciclo</option>
  <optgroup label="Grado superior">
    <option value="dam">Desarrollo de aplicaciones multiplataforma</option>
    <option value="daw">Desarrollo de aplicaciones web</option>
  </optgroup>
</select>

    Resultado visual:

    EtiquetaAtributosUso
    selectid, name, required, disabledIdentifican el control, el nombre enviado, su obligatoriedad y su disponibilidad.
    selectmultiple, sizePermiten varias selecciones y establecen cuántas opciones se muestran a la vez.
    optionvalueValor enviado al elegirla. Si falta, se utiliza su texto.
    optionselected, disabledSelección inicial y opción que no puede elegirse.
    optgrouplabel, disabledAgrupa opciones bajo un título; puede deshabilitar todo ese grupo.

    En el ejemplo se ve el nombre completo del ciclo, pero se enviaría ciclo=dam o ciclo=daw. La opción inicial tiene valor vacío y no satisface required.

    <label for="talleres-ejemplo">Talleres (puedes elegir varios):</label>
<select id="talleres-ejemplo" name="talleres" multiple size="3">
  <option value="html">HTML</option>
  <option value="css">CSS</option>
  <option value="xml">XML</option>
</select>

    Resultado visual:

    En muchos equipos, para seleccionar opciones separadas se mantiene pulsada Ctrl o Cmd; con Mayús se selecciona un intervalo. En móviles la interacción puede ser distinta. Cada opción seleccionada aporta un valor con el mismo name.

    Texto de varias líneas: textarea

    <textarea> permite escribir comentarios o mensajes con saltos de línea. Tiene apertura y cierre: el contenido inicial se escribe entre las etiquetas, no mediante un atributo value.

    <label for="mensaje-ejemplo">Mensaje:</label><br>
<textarea id="mensaje-ejemplo" name="mensaje" rows="4" cols="25"
          maxlength="300" placeholder="Cuéntanos tu consulta"></textarea>

    Resultado visual:


    rows y cols indican su tamaño visible aproximado en filas y columnas; no limitan la cantidad de texto. Para la longitud utilizamos minlength y maxlength. También admite required, readonly y disabled.

    <textarea name="observaciones" aria-label="Observaciones">Texto inicial editable.</textarea>

    Normalmente utilizaremos un label visible. El atributo aria-label del último ejemplo proporciona un nombre accesible cuando no hay una etiqueta visible.

    Agrupar campos: fieldset y legend

    <fieldset> reúne controles relacionados. Su primer elemento <legend> pone nombre al grupo, por ejemplo «Datos de contacto» o «Turno preferido». Cada campo sigue necesitando su propia etiqueta.

    <fieldset>
  <legend>Datos de contacto</legend>
  <p>
    <label for="contacto-nombre">Nombre:</label>
    <input type="text" id="contacto-nombre" name="nombre">
  </p>
  <p>
    <label for="contacto-correo">Correo:</label>
    <input type="email" id="contacto-correo" name="correo">
  </p>
</fieldset>

    Resultado visual:

    Datos de contacto

    fieldset admite disabled para deshabilitar los controles del grupo, con la excepción de los que estén dentro de su primera legend. En nuestros ejemplos, la leyenda solo contendrá el título.

    Botones: button, submit y reset

    <button> crea un botón cuyo texto se escribe entre la apertura y el cierre. No existe una etiqueta <submit>: submit es un valor del atributo type.

    typeComportamientoEjemplo
    submitSolicita validar y enviar el formulario.<button type="submit">Enviar</button>
    resetDevuelve los campos a sus valores iniciales. No necesariamente los deja vacíos.<button type="reset">Restablecer</button>
    buttonNo tiene una acción automática; normalmente se le asociará comportamiento con JavaScript.<button type="button">Otra acción</button>

    Dentro de un formulario, un button sin type normalmente actúa como botón de envío. Para evitar envíos por accidente, indicaremos siempre el tipo.

    <button type="submit" name="accion" value="inscribir">Enviar inscripción</button>
<button type="reset">Restablecer</button>
<button type="button" disabled>Acción no disponible</button>

<!-- Alternativa con input: el texto se escribe en value. -->
<input type="submit" value="Enviar inscripción">

    disabled impide activar el botón. Si un botón de envío tiene name y value, aporta ese par de datos cuando es el botón utilizado para enviar. El texto visible de button puede ser distinto de su value.

    Como ampliación, un botón de envío puede usar formaction y formmethod para cambiar el destino o método de ese envío concreto. Para los formularios iniciales bastará con configurarlos en form.

    Archivos y campos ocultos

    Un input de tipo file permite seleccionar archivos del dispositivo. Para enviar su contenido, el formulario debe usar method="post" y enctype="multipart/form-data".

    <form action="/adjuntos" method="post" enctype="multipart/form-data">
  <label for="archivo-ejemplo">Adjunta imágenes o documentos PDF:</label>
  <input type="file" id="archivo-ejemplo" name="documentos"
         accept="image/*,.pdf" multiple>
  <button type="submit">Enviar archivos</button>
</form>

    Resultado visual del selector:

    multiple permite varios archivos. accept orienta al selector sobre los formatos esperados; el receptor debe comprobarlos igualmente. Elegir un archivo no lo sube automáticamente.

    Un campo hidden envía un dato sin mostrar un control:

    <input type="hidden" name="actividad" value="taller-html">

    Se enviaría actividad=taller-html. Que esté oculto no lo hace secreto ni impide modificarlo desde las herramientas del navegador.

    Sugerencias de texto: datalist

    <datalist> ofrece sugerencias para un input. El atributo list del campo apunta al id de la lista. A diferencia de un select, la persona puede escribir otro valor.

    <label for="editor-ejemplo">Editor preferido:</label>
<input type="text" id="editor-ejemplo" name="editor" list="editores-ejemplo">
<datalist id="editores-ejemplo">
  <option value="Visual Studio Code"></option>
  <option value="Notepad++"></option>
  <option value="IntelliJ IDEA"></option>
</datalist>

    Resultado visual:

    La apariencia y la forma de mostrar las sugerencias dependen del navegador. La lista no impone por sí misma que el valor escrito pertenezca a las sugerencias.

    Qué se envía: GET y POST

    El envío utiliza pares nombre=valor. Por ejemplo, un campo con name="nombre" cuyo contenido actual sea Ane aporta nombre=Ane.

    MétodoDónde van los datosUso habitual
    getEn la URL, como parámetros después de ?.Búsquedas y filtros que consultan información.
    postEn el cuerpo de la petición, no añadidos a la URL por el formulario.Inscripciones, mensajes o subida de archivos.
     
    <form action="/buscar" method="get">
  <label for="busqueda">Buscar:</label>
  <input type="search" id="busqueda" name="q">
  <button type="submit">Buscar</button>
</form>

    Si escribimos html, el navegador solicitaría /buscar?q=html. Cuando hay varios datos, se separan con &; el navegador codifica los caracteres que lo necesitan.

    • Los campos de datos sin name y los controles deshabilitados no se incluyen.
    • Los campos compatibles con readonly sí pueden enviar su valor.
    • Las casillas y radios solo aportan datos si están seleccionados.
    • Un select aporta los valores de sus opciones seleccionadas y habilitadas.

    POST no cifra los datos: para cifrar la comunicación se utiliza HTTPS. En esta unidad aprenderemos a construir formularios y entender sus datos; su procesamiento en un servidor se trabajará más adelante.

    Errores frecuentes y documentación

    • Usar el mismo id para varios controles o escribir un for que no coincide.
    • Confundir name con id y olvidar el nombre del dato enviado.
    • Dar nombres distintos a los radios de un mismo grupo.
    • Utilizar checked en una opción de select: en option se usa selected.
    • Escribir <submit> o <options> en lugar de las etiquetas y atributos correctos.
    • Confundir una pista placeholder con una etiqueta o un valor inicial.
    • Esperar que un formulario guarde información sin disponer de un receptor que la procese.

    Para ampliar, consulta la introducción a formularios de W3Schools y la documentación de controles de formulario de MDN.
