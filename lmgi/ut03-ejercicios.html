    3.1 Ejercicios de estructura básica HTML

    Actividades incrementales para practicar la estructura mínima de un documento HTML.

    Preparación

    Crea una carpeta llamada ut03-html. Dentro de ella guarda cada actividad en un archivo HTML diferente.

    Abre los archivos en el navegador para comprobar el resultado y revisa el código en Visual Studio Code.

    Actividad 1: documento mínimo

    Crea un archivo llamado actividad-01.html con la estructura mínima de una página HTML.

    • Debe incluir <!DOCTYPE html>.
    • Debe incluir las etiquetas <html>, <head> y <body>.
    • Dentro de <head>, añade un <title>.
    • Dentro de <body>, escribe un título principal y un párrafo.

    Actividad 2: idioma y codificación

    Crea un archivo llamado actividad-02.html a partir del anterior, pero añadiendo información de idioma y codificación.

    • Incluye el atributo lang="es" en la etiqueta <html>.
    • Añade <meta charset="UTF-8"> dentro de <head>.
    • Escribe un texto que contenga tildes y la letra ñ.
    • Comprueba que se visualiza correctamente en el navegador.

    Actividad 3: head frente a body

    Crea un archivo llamado actividad-03.html y separa correctamente la información del documento.

    • En <head>, incluye el título de la pestaña del navegador.
    • En <body>, incluye el contenido visible de la página.
    • Comprueba que el contenido de <title> no aparece dentro de la página, sino en la pestaña.
    • Añade un comentario HTML explicando qué parte se ve y qué parte no se ve directamente.
    <!-- Este comentario no se muestra en la página -->

    Actividad 4: corrige una página rota

    Crea un archivo llamado actividad-04.html y corrige el siguiente código para que tenga una estructura HTML válida.

    <html>
<title>Página rota</title>
<body>
  <h1>Mi página
  <p>Este documento tiene varios problemas.
</html>

    Después de corregirlo, añade un comentario indicando qué errores has encontrado.

    Actividad 5: página personal básica

    Crea un archivo llamado actividad-05.html que represente una página personal sencilla.

    • Debe tener estructura HTML completa.
    • Debe tener un título de pestaña adecuado.
    • Debe indicar el idioma del documento.
    • Debe incluir al menos tres bloques de contenido visible en el <body>.
    • Debe tener un comentario HTML en alguna parte del documento.

    3.2 Ejercicios de etiquetas básicas de texto

    Actividades incrementales para practicar títulos, párrafos, texto en línea y listas.

    Actividad 1: jerarquía de títulos

    Crea un archivo llamado texto-01.html sobre un tema que te interese.

    • Utiliza un único <h1> como título principal.
    • Utiliza al menos dos <h2> para secciones principales.
    • Utiliza al menos dos <h3> para subsecciones.
    • No elijas los encabezados por su tamaño visual, sino por la importancia del contenido.

    Actividad 2: párrafos y saltos de línea

    Crea un archivo llamado texto-02.html con tres párrafos sobre una película, serie, videojuego o libro.

    • Utiliza la etiqueta <p> para cada párrafo.
    • Incluye un salto de línea con <br> en uno de los párrafos.
    • Añade una separación temática con <hr>.
    • Comprueba la diferencia entre crear un párrafo nuevo y usar un salto de línea.

    Actividad 3: destacar texto correctamente

    Crea un archivo llamado texto-03.html con un pequeño texto de avisos para el aula.

    • Usa <strong> para marcar información realmente importante.
    • Usa <b> para resaltar una palabra solo de forma visual.
    • Usa <em> para dar énfasis a una frase.
    • Usa <i> para una palabra extranjera, técnica o especial.

    Al final del archivo, añade un comentario explicando la diferencia entre <strong> y <b>.

    Actividad 4: listas ordenadas y no ordenadas

    Crea un archivo llamado texto-04.html con dos listas.

    • Una lista no ordenada con materiales necesarios para trabajar HTML.
    • Una lista ordenada con los pasos para crear y abrir una página HTML.
    • Cada elemento debe estar dentro de una etiqueta <li>.
    • Añade un título antes de cada lista.

    Actividad 5: miniartículo HTML

    Crea un archivo llamado texto-05.html con un miniartículo sobre una tecnología, afición o tema de actualidad.

    • Debe tener una estructura HTML completa.
    • Debe incluir títulos jerárquicos.
    • Debe incluir varios párrafos.
    • Debe usar <span> para marcar una palabra o expresión concreta.
    • Debe incluir texto destacado con <strong> y texto enfatizado con <em>.
    • Debe incluir al menos una lista.

    3.3 Ejercicios de tablas HTML

    Actividades incrementales para practicar tablas, cabeceras, cuerpos, pies y celdas combinadas.

    Actividad 1: tabla sencilla de datos

    Crea un archivo llamado tablas-01.html con una tabla de tres filas y tres columnas.

    • La tabla debe representar datos reales, por ejemplo: personas, módulos, videojuegos, ciudades o productos.
    • Utiliza <table>, <tr> y <td>.
    • Añade un título principal antes de la tabla.
    • Comprueba que cada fila tenga el mismo número de celdas.

    Actividad 2: cabeceras y título de tabla

    Crea un archivo llamado tablas-02.html con una tabla de horario semanal sencilla.

    • Utiliza <caption> para poner un título a la tabla.
    • Utiliza <th> para las cabeceras de columna.
    • Incluye al menos cuatro filas de datos.
    • Incluye al menos tres columnas.

    Actividad 3: thead, tbody y tfoot

    Crea un archivo llamado tablas-03.html con una tabla de notas, puntuaciones o resultados.

    • Separa la tabla en <thead>, <tbody> y <tfoot>.
    • En <thead>, coloca las cabeceras.
    • En <tbody>, coloca al menos cuatro registros.
    • En <tfoot>, coloca una fila de resumen, media, total o conclusión.

    Actividad 4: combinar columnas con colspan

    Crea un archivo llamado tablas-04.html con una tabla que utilice colspan.

    • La primera fila debe tener una celda que ocupe varias columnas.
    • Después, añade una fila con las cabeceras reales de la tabla.
    • Incluye al menos tres filas de datos.
    • El resultado debe entenderse como una tabla coherente, no como celdas combinadas al azar.

    Ideas posibles: menú semanal, clasificación deportiva, planificación de tareas o resumen de compras.

    Actividad 5: combinar filas con rowspan

    Crea un archivo llamado tablas-05.html con una tabla que utilice rowspan.

    • Debe haber una celda que ocupe al menos dos filas.
    • La tabla debe tener cabeceras con <th>.
    • Incluye al menos cuatro filas de contenido.
    • Añade un comentario HTML indicando qué celda ocupa varias filas.

    Ideas posibles: módulos por turno, productos por categoría, tareas por responsable o actividades por día.

    Actividad 6: tabla completa combinada

    Crea un archivo llamado tablas-06.html con una tabla más completa que combine varios conceptos.

    • Debe incluir <caption>.
    • Debe usar <thead>, <tbody> y <tfoot>.
    • Debe incluir al menos un colspan.
    • Debe incluir al menos un rowspan.
    • Debe usar algún atributo scope en una cabecera.

    Antes de escribir el HTML, dibuja la tabla en papel o en una hoja aparte para decidir cuántas columnas reales tendrá.

    3.4 Ejercicios de refuerzo HTML

    Tanda de ejercicios progresivos para practicar estructura HTML, encabezados, párrafos, enlaces, imágenes, listas y tablas.

    Algunos ejercicios incluyen pequeños detalles visuales. Si aparece algún estilo que todavía no controlas, puedes copiarlo de forma guiada: CSS se trabajará con más profundidad en la siguiente unidad.

    Bloque 1: encabezados

    Ejercicio 1A: Crear una página simple con un título

    Crea un archivo HTML que contenga un título en la pestaña del navegador y un encabezado grande dentro del cuerpo de la página.

    • Crea la estructura básica: <!DOCTYPE html>, <html>, <head> y <body>.
    • Añade un título para la página dentro de <title>.
    • Dentro de <body>, añade un título usando <h1>.

    Resultado esperado: una página con un título grande en la parte superior.

    Ejercicio 1B: Crear una página con un título y un subtítulo

    Crea un archivo HTML con un título en la pestaña del navegador, un encabezado principal y un subtítulo en el cuerpo de la página.

    • Crea la estructura básica de una página HTML.
    • Añade un título para la página dentro de <title>.
    • Dentro de <body>, añade un título con <h1> y debajo un subtítulo con <h2>.

    Resultado esperado: una página con un título grande y un subtítulo más pequeño justo debajo.

    Ejercicio 1C: Crear una página con múltiples encabezados

    Crea un archivo HTML con un título en la pestaña del navegador y tres encabezados de distintos niveles en el cuerpo de la página.

    • Crea la estructura básica de una página HTML.
    • Añade un título para la página dentro de <title>.
    • Dentro de <body>, añade encabezados con <h1>, <h2> y <h3>.

    Resultado esperado: una página con tres encabezados de tamaño decreciente y niveles de importancia distintos.

    Bloque 2: párrafos

    Ejercicio 2A: Crear un párrafo con texto

    Añade un párrafo a la página que describa quién eres o cualquier tema que te interese.

    • Después del <h1>, añade un párrafo con <p>.
    • Escribe un breve texto dentro del párrafo.

    Resultado esperado: una página con un título y un párrafo de texto.

    Ejercicio 2B: Crear una página con tus aficiones

    Crea un archivo HTML que incluya un título y varios párrafos en los que describas tus aficiones.

    • Añade un título usando <h1>.
    • Después del título, añade varios párrafos con <p>.
    • Describe cada afición en un párrafo distinto.

    Resultado esperado: una página con un título y varios párrafos sobre tus aficiones.

    Ejercicio 2C: Crear una web sobre lugares que te gusten

    Crea un archivo HTML con un título principal y varios apartados que describan lugares que te gusten.

    • Añade un título principal con <h1>.
    • Añade varios párrafos con <p> describiendo lugares de tu preferencia.
    • Por cada lugar, añade un título secundario indicando su nombre. Puedes usar <h2> o <h3>.

    Resultado esperado: una página con lugares descritos mediante encabezados y párrafos.

    Bloque 3: enlaces

    Ejercicio 3A: Añadir enlaces

    Crea una página HTML con un título, un párrafo y un enlace que lleve a otro sitio web.

    • Utiliza la etiqueta <a> para crear un enlace en el texto.
    • El atributo href debe contener la URL del sitio web al que quieres enlazar.

    Resultado esperado: una página con un enlace que redirige a otro sitio web al hacer clic.

    Ejercicio 3B: Crear una página de enlaces a redes sociales

    Crea una página HTML con un título, un párrafo de texto y varios enlaces a redes sociales.

    • Añade un título usando <h1>.
    • Añade un párrafo breve sobre el uso de redes sociales.
    • Crea varios enlaces con <a> que dirijan a diferentes redes sociales.

    Resultado esperado: una página con varios enlaces funcionales.

    Bloque 4: imágenes

    Ejercicio 4A: Insertar una imagen

    Crea una página con una imagen usando la etiqueta <img>.

    • Utiliza <img> con el atributo src para añadir una imagen almacenada en la misma carpeta que el HTML.
    • Añade un texto alternativo con el atributo alt.

    Resultado esperado: una página que muestra una imagen.

    Ejercicio 4B: Insertar varias imágenes de paisajes

    Crea una página con tres imágenes de paisajes usando <img>.

    • Utiliza <img> con el atributo src para cada imagen.
    • Añade un atributo alt que describa cada paisaje.

    Resultado esperado: una página que muestra tres imágenes de paisajes.

    Ejercicio 4C: Insertar varias imágenes de animales con descripciones

    Crea una página con cuatro imágenes de animales diferentes usando <img>.

    • Utiliza <img> con src para cada imagen.
    • Añade un atributo alt que describa cada animal.
    • Añade una cabecera para cada imagen utilizando etiquetas de título.

    Resultado esperado: una página con cuatro imágenes y sus nombres correspondientes.

    Bloque 5: listas desordenadas

    Ejercicio 5A: Crear una lista desordenada

    Crea una lista desordenada para enumerar tus hobbies o intereses.

    • Utiliza <ul> para crear una lista desordenada.
    • Utiliza <li> para cada elemento de la lista.

    Resultado esperado: una página que muestra una lista con varios elementos.

    Ejercicio 5B: Crear listas de películas y canciones favoritas

    Crea dos listas desordenadas: una de películas favoritas y otra de canciones favoritas.

    • Utiliza una etiqueta <ul> para la lista de películas.
    • Utiliza otra etiqueta <ul> para la lista de canciones.
    • Haz que cada elemento se muestre con un cuadrado en vez de con un círculo.

    Resultado esperado: dos listas de favoritos en formato de viñetas.

    Ejercicio 5C: Crear cuatro listas de favoritos

    Crea cuatro listas desordenadas: comidas, libros, películas y canciones favoritas.

    • Utiliza <ul> y <li> para cada lista.
    • Haz que el tipo de viñeta sea círculo y que el espaciado entre elementos sea del 150%.
    • Por cada lista, añade una cabecera correspondiente.
    • Entre cada cabecera y su lista, añade un párrafo con un pequeño resumen.
    • Añade una URL relacionada con cada lista para redirigir a una web de rankings o recomendaciones.

    Resultado esperado: una página web completa con listados, textos y enlaces.

    Bloque 6: listas ordenadas y listas anidadas

    Ejercicio 6A: Lista ordenada de pasos para prepararte para el día

    Crea una lista ordenada con los pasos que sigues para prepararte cada mañana.

    • Usa <ol> para la lista ordenada y <li> para cada paso.
    • Haz que el listado comience en el número 9 usando el atributo adecuado.

    Resultado esperado: una lista numerada que empieza en 9.

    Ejercicio 6B: Lista ordenada de instrucciones

    Crea una lista ordenada con los pasos para realizar una tarea, como limpiar tu escritorio.

    • Usa <ol> para crear la lista ordenada.
    • Cada paso debe estar dentro de <li>.
    • La numeración debe mostrarse con letras.
    • Añade un espaciado del 130% entre elementos.

    Resultado esperado: una lista ordenada con instrucciones.

    Ejercicio 6C: Lista de temas con subtemas

    Crea una lista desordenada de temas y, dentro de cada tema, una lista ordenada de subtemas.

    • Usa <ul> para los temas principales.
    • Dentro de cada <li>, usa <ol> para los subtemas.

    Resultado esperado: una lista con elementos principales y sublistas numeradas.

    Bloque 7: tablas básicas

    Ejercicio 7A: Crear una tabla básica

    Crea una tabla sencilla que muestre la información de un horario de clases.

    • Utiliza <table> para crear la tabla.
    • Utiliza <tr> para crear filas.
    • Utiliza <th> para los encabezados, por ejemplo: asignatura, hora y día.
    • Utiliza <td> para los datos de cada celda.

    Resultado esperado: una tabla básica con varias filas y columnas.

    Ejercicio 7B: Tabla de datos de estudiantes

    Crea una tabla con datos de estudiantes: nombre, edad y calificación. Añade al menos tres estudiantes.

    • Utiliza <table> para crear la tabla.
    • Utiliza <tr> para crear filas.
    • Utiliza <th> para los encabezados.
    • Utiliza <td> para los datos de cada celda.

    Resultado esperado: una tabla con datos básicos de estudiantes.

    Bloque 8: tablas completas y combinadas

    Ejercicio 8A: Crear una tabla con encabezados y múltiples filas

    Crea una tabla que muestre un catálogo de productos de papelería, incluyendo nombre del producto, precio y disponibilidad.

    • Utiliza <table> para crear la tabla.
    • Usa <thead> para agrupar los encabezados.
    • Usa <tbody> para agrupar el cuerpo de la tabla.
    • Usa varias filas con <tr> y datos con <td>.

    Resultado esperado: una tabla con encabezados y varias filas de productos.

    Ejercicio 8B: Catálogo de productos con detalles

    Crea una página HTML que muestre un catálogo de productos. Cada producto debe tener imagen, descripción, precio, disponibilidad y categoría.

    • Crea la estructura básica de la página HTML.
    • En el <head>, añade un título que diga Catálogo de Productos.
    • Dentro del <body>, crea una tabla con <table>, <thead> y <tbody>.
    • En el <thead>, incluye los encabezados: imagen, nombre del producto, descripción, precio, disponibilidad y categoría.
    • En el <tbody>, crea al menos tres filas de productos.
    • Utiliza <img> dentro de una celda para mostrar la imagen de cada producto.

    Resultado esperado: una tabla de catálogo con información completa de varios productos.

    Ejercicio 8C: Horario de conferencia

    Crea una tabla que muestre el horario de una conferencia con sesiones en diferentes salas. Algunas sesiones ocuparán más de una hora y algunas combinarán varias salas.

    • Crea la estructura básica de la página HTML.
    • En el <head>, añade un título descriptivo como Horario de Conferencia.
    • Dentro del <body>, crea una tabla con <table>, <thead> y <tbody>.
    • En el <thead>, incluye los encabezados: hora, sala 1, sala 2 y sala 3.
    • Utiliza rowspan para las sesiones que duren varias horas.
    • Utiliza colspan para las sesiones que combinen varias salas.

    Resultado esperado: una tabla de horario con celdas combinadas correctamente.

    3.5 Ejercicios de formularios HTML

    Diez actividades progresivas para construir formularios con etiquetas, controles, selección de opciones y validación.

    Preparación y normas comunes

    Crea una carpeta formularios dentro de ut03-html. Cada actividad será un documento HTML completo, con idioma español, codificación UTF-8, título de pestaña, un h1 y una breve explicación de su propósito.

    Trabaja con HTML, sin JavaScript ni Bootstrap. Puedes organizar los campos mediante párrafos, fieldset y legend. La apariencia se trabajará con CSS más adelante.

    • Asocia cada control visible con su label, utilizando for e id. No repitas identificadores dentro del mismo documento.
    • Asigna un name a cada dato que deba enviarse e indica valores explícitos en radios, casillas y opciones.
    • Escribe el type de cada botón e indica junto a los campos cuáles son obligatorios.
    • Utiliza datos inventados para las pruebas.

    Salvo en la actividad de archivos, configura method="get" y como action el nombre del propio archivo, por ejemplo action="formulario-01.html". Al enviar, la página se volverá a abrir y podrás observar los datos en su URL. Esto permite estudiar el envío, pero no almacena una inscripción ni ejecuta un programa receptor.

    Actividad 1: primer formulario de contacto

    Crea formulario-01.html con un formulario para solicitar información sobre un taller.

    • Incluye nombre y correo, ambos obligatorios, con tipos text y email.
    • Utiliza los nombres de envío nombre y correo.
    • Añade un botón submit con el texto «Solicitar información».
    • El id del nombre será distinto de su name, para comprobar que cumplen funciones diferentes.

    Comprueba: pulsa cada etiqueta y observa si se enfoca el campo correspondiente. Intenta enviar vacío, introduce un correo con formato incorrecto y finalmente envía datos válidos. Localiza en la URL los nombres de los datos enviados.

    Actividad 2: longitudes y patrones

    Crea formulario-02.html para registrar un alias y unos datos de contacto.

    • Alias obligatorio de entre 3 y 15 caracteres.
    • Código postal obligatorio formado exactamente por cinco dígitos. Utiliza texto y un pattern, para poder conservar ceros iniciales.
    • Teléfono opcional: si se completa, debe contener exactamente nueve dígitos. Utiliza type="tel" y un patrón.
    • Incluye ejemplos mediante placeholder, manteniendo etiquetas visibles.
    • Añade un botón de envío y otro para restablecer.

    Comprueba: prueba alias de 2, 3 y 15 caracteres, un código postal con letras y otro que empiece por cero. Deja el teléfono vacío y después introduce uno de ocho dígitos. Explica por qué el teléfono vacío es admisible y el código postal vacío no.

    Actividad 3: reserva de una visita

    Crea formulario-03.html para reservar una visita a una exposición.

    • Nombre y correo obligatorios.
    • Cantidad de asistentes obligatoria: entre 1 y 6, sin decimales.
    • Fecha obligatoria entre el 1 y el 30 de noviembre de 2026, ambos incluidos.
    • Hora obligatoria entre las 09:00 y las 18:00, en intervalos de 30 minutos.
    • Un control de color para elegir el color de la acreditación, con un valor inicial.

    Comprueba: intenta enviar 0 asistentes, 7 y una cantidad decimal. Prueba los extremos de fecha y hora y un valor intermedio no permitido, como las 09:15. Observa cómo cambian los controles según su type.

    Actividad 4: dos grupos de radio independientes

    Crea formulario-04.html para elegir las preferencias de un curso.

    • Añade un grupo obligatorio «Turno» con mañana y tarde, sin selección inicial.
    • Añade un grupo «Modalidad» con presencial y a distancia, con presencial seleccionado inicialmente.
    • Todos los radios de un grupo compartirán name, pero cada radio tendrá un id diferente.
    • Agrupa cada conjunto con fieldset y legend.
    • Añade botones de envío y restablecimiento.

    Comprueba: debes poder elegir simultáneamente un turno y una modalidad, pero nunca dos turnos. Intenta enviar sin turno y después restablece: comprueba que se recupera la modalidad inicial y que el turno vuelve a quedar sin marcar.

    Actividad 5: casillas y preferencias múltiples

    Crea formulario-05.html para elegir temas de una revista digital.

    • Incluye cuatro casillas de intereses: tecnología, cine, música y viajes. Compartirán name="intereses" y tendrán valores distintos.
    • Marca música inicialmente. Los intereses serán opcionales y se podrá marcar cualquier cantidad.
    • Añade una casilla independiente y obligatoria para aceptar las condiciones ficticias de la actividad, con su propio nombre y valor.
    • Añade una casilla opcional para recibir avisos.
    • Incluye una breve explicación visible de qué opciones son obligatorias.

    Comprueba: envía dos intereses y observa sus valores repetidos bajo el mismo nombre. Desmarca todos y compara la URL. Explica qué sucede con las casillas desmarcadas y por qué no has puesto required en cada interés.

    Actividad 6: select, option y optgroup

    Crea formulario-06.html para elegir un destino y varias actividades.

    • Un select obligatorio de destino con una opción inicial de valor vacío que indique «Elige un destino».
    • Incluye al menos seis destinos, agrupados en dos optgroup con un título mediante label.
    • Una de las opciones será visible pero estará deshabilitada por no tener plazas.
    • Otro select permitirá elegir varias actividades. Tendrá al menos cuatro opciones y mostrará cuatro filas.
    • Los valores enviados serán códigos breves, diferentes de los textos completos que se muestran.

    Comprueba: intenta enviar sin destino. Selecciona varias actividades y observa los datos enviados. Comprueba que no puedes elegir el destino deshabilitado y que selected establece una selección inicial.

    Actividad 7: mensajes y sugerencias

    Crea formulario-07.html para recibir propuestas para una biblioteca.

    • Nombre obligatorio y asunto obligatorio, con un máximo de 60 caracteres.
    • Mensaje obligatorio en un textarea de al menos cinco filas, con un mínimo de 20 y un máximo de 400 caracteres.
    • Incluye un texto inicial editable dentro de textarea, distinto de un placeholder.
    • Un campo de texto para proponer un género literario, asociado mediante list a un datalist con al menos cuatro sugerencias.
    • Añade un botón para restablecer los campos.

    Comprueba: cambia el mensaje y restablece el formulario: debe volver su texto inicial. Escribe un género no incluido en las sugerencias y verifica que es admisible. Explica la diferencia entre el tamaño visible del mensaje y su longitud máxima.

    Actividad 8: valores iniciales y campos deshabilitados

    Crea formulario-08.html para modificar una ficha ficticia.

    • Nombre editable con un valor inicial.
    • Código de ficha de texto con name, un valor inicial y readonly.
    • Grupo de datos de una promoción futura dentro de un fieldset disabled, que contenga dos controles con nombre y valor.
    • Un campo hidden con el nombre origen y el valor ficha-html.
    • Un botón de envío con name="accion" y value="actualizar", y otro de tipo reset.

    Comprueba: identifica qué datos llegan a la URL. El código de ficha y el campo oculto deben aparecer; los controles deshabilitados, no. Modifica el nombre y restablece: debe recuperar su valor inicial, no quedar necesariamente vacío.

    Actividad 9: preparar una subida de archivos

    Crea formulario-09.html con la estructura de un formulario para adjuntar trabajos. Esta actividad estudia su preparación: no disponemos de un servidor que reciba los archivos.

    • Configura method="post", enctype="multipart/form-data" y un destino ficticio action="/entregas".
    • Incluye un nombre obligatorio y una descripción en textarea.
    • Un selector de un documento PDF, obligatorio.
    • Otro selector de imágenes opcionales que permita elegir varios archivos.
    • Utiliza accept para orientar cada selector y añade un botón de restablecimiento.
    • Incluye el botón de envío, pero déjalo disabled y acompáñalo del texto «Demostración sin servidor receptor».

    Comprueba: selecciona archivos y prueba el restablecimiento. Explica por qué este formulario no utiliza GET, para qué sirve enctype y por qué accept no sustituye la comprobación del archivo en el servidor. No intentes enviar al destino ficticio.

    Actividad 10: inscripción completa a una jornada

    Crea formulario-10.html, reuniendo los controles anteriores en una inscripción a una jornada cultural.

    Comprueba: prepara una ejecución válida y cinco pruebas con valores ausentes o no válidos. Anota qué control impide cada envío y por qué. Revisa también qué datos no aparecen cuando no marcas las preferencias.

    Revisión final

    En cada actividad, recorre los controles con la tecla Tab, activa las opciones mediante sus etiquetas y comprueba el restablecimiento. Revisa que los nombres enviados sean comprensibles, que cada grupo de radios sea independiente y que ningún placeholder sustituya a una etiqueta visible.

    3.6 Páginas completas con formularios

    Cinco proyectos progresivos para combinar páginas completas, formularios, tablas, imágenes y navegación en un mismo sitio.

    Normas comunes de los proyectos

    Crea una carpeta independiente por proyecto y una subcarpeta img para sus imágenes. Cada archivo HTML tendrá su estructura completa, idioma español, UTF-8, un título de pestaña propio, un h1 y encabezados organizados por niveles.

    • Utiliza enlaces relativos entre páginas del proyecto y enlaces con #id para saltar a secciones.
    • Las imágenes serán locales y tendrán un alt adecuado. Puedes utilizar fotografías propias, imágenes que tengas permiso de usar o SVG creados por ti.
    • Utiliza tablas para datos, no para colocar las partes de la página. Añade un caption y cabeceras con th y scope cuando corresponda.
    • Para ver los bordes, puedes reutilizar el CSS de la teoría 3.3 dentro de style en el head. No se exige más CSS, JavaScript ni Bootstrap.
    • Cada formulario tendrá etiquetas asociadas, nombres de envío, valores explícitos y tipos de botón. Informa de los campos obligatorios.

    Utiliza datos ficticios. Configura los formularios con GET y como destino el propio archivo que los contiene para poder revisar los datos en la URL. Los proyectos simulan reservas o solicitudes: no guardan datos, calculan pagos ni envían correos.

    Proyecto 1: taller de fotografía

    Crea taller-fotografia/index.html: una página completa que presente un taller y permita solicitar plaza.

    • Presentación con título principal, dos párrafos, una imagen y una lista del material necesario.
    • Índice inicial con enlaces a «Presentación», «Horario» e «Inscripción», situados en esa misma página.
    • Tabla de horario con al menos tres sesiones y columnas de fecha, hora y tema.
    • Formulario de nombre y correo obligatorios, selector obligatorio de sesión y observaciones opcionales de hasta 200 caracteres.
    • Una casilla opcional para solicitar préstamo de cámara y botones de envío y restablecimiento.
    • Enlace «Volver al principio» al final y un enlace externo a un recurso sobre fotografía, con un texto que explique su destino.

    Los códigos y textos de las sesiones del formulario deben corresponderse con los de la tabla.

    Comprueba: navega por el índice, envía una solicitud válida y confirma en la URL la sesión elegida. Cambia el tamaño de la ventana y revisa que todos los contenidos sigan siendo legibles.

    Proyecto 2: club de lectura

    Crea club-lectura con tres páginas: index.html, lecturas.html e inscripcion.html. Las tres mostrarán los mismos enlaces de navegación.

    • Portada: presentación del club, imagen y lista de sus normas.
    • Lecturas: tabla con al menos cuatro libros, su autoría y la fecha de reunión. Añade una imagen relacionada con el club o una lectura.
    • Inscripción: nombre y correo obligatorios, grupo de radios para el turno, y selector de la primera lectura en la que se desea participar.
    • El formulario incluirá casillas opcionales de géneros favoritos, un mensaje de presentación y una aceptación obligatoria de las normas ficticias.
    • Desde la portada, enlaza directamente a una sección identificada dentro de lecturas.html, combinando el nombre del archivo y un fragmento #id.

    Organiza el formulario con al menos dos fieldset. El texto completo de cada libro aparecerá en el selector, pero su value será un código breve.

    Comprueba: visita todas las páginas desde cualquiera de ellas. Asegúrate de que una selección de lectura siempre corresponde a un libro de la tabla y de que los enlaces funcionan después de mover la carpeta completa a otra ubicación.

    Proyecto 3: restaurante y solicitud de reserva

    Crea restaurante con index.html, carta.html y reservas.html, conectadas mediante navegación relativa.

    • Portada con presentación, una imagen y enlaces a la carta y la reserva.
    • Carta con al menos seis platos agrupados por categorías, dos imágenes y una tabla de plato, descripción y precio.
    • Utiliza thead, tbody y una fila de título que combine columnas mediante colspan.
    • Reserva con nombre, correo, teléfono de nueve dígitos y cantidad de comensales de 1 a 8; todos obligatorios.
    • Incluye una fecha entre el 1 y el 30 de noviembre de 2026 y un selector obligatorio con al menos cuatro horas de reserva.
    • Grupo de radios para interior o terraza, casillas opcionales de necesidades de la reserva y observaciones limitadas a 300 caracteres.
    • Incluye enlaces entre las condiciones de reserva y el formulario, y un enlace para volver al inicio de la página.

    Explica junto al formulario que se trata de una solicitud y no de una confirmación automática de disponibilidad. No es necesario calcular precios ni comprobar reservas de otras personas.

    Comprueba: intenta reservar para 0, 1, 8 y 9 personas. Verifica los límites de fecha, el teléfono y la elección excluyente de interior o terraza. Asegúrate de que las imágenes cargan desde las tres páginas.

    Proyecto 4: jornadas de videojuegos

    Comprueba: recorre todas las rutas desde la portada y desde las páginas interiores. Revisa las celdas combinadas, intenta elegir la actividad completa y comprueba que los datos de la inscripción coinciden con la actividad publicada.

    Proyecto 5: web de actividades de naturaleza

    Crea un sitio llamado naturaleza con cuatro páginas: index.html, actividades.html, solicitud.html y contacto.html. Organiza al menos dos páginas en una subcarpeta y conserva una carpeta común de imágenes.

    • Portada con presentación, dos imágenes, una lista de recomendaciones y enlaces al catálogo y la solicitud.
    • Catálogo con al menos cinco actividades de dos categorías distintas. Cada actividad tendrá un identificador al que se pueda enlazar.
    • Tabla comparativa con actividad, duración, dificultad, precio orientativo y disponibilidad. Incluye cabeceras, cuerpo, pie explicativo y al menos una combinación de celdas justificada por los datos.
    • Desde cada actividad del catálogo, incluye un enlace a la sección de solicitud de solicitud.html. La persona seleccionará manualmente allí la actividad; no es necesario rellenarla automáticamente.
    • Formulario de solicitud organizado en grupos: datos de contacto, actividad y preferencias. Incluye nombre, correo, teléfono, cantidad de participantes de 1 a 10 y fecha dentro del mes de noviembre de 2026, todos obligatorios.
    • Selector de actividad agrupado por categoría, con una opción no disponible deshabilitada; radios de turno; varias casillas de servicios opcionales y observaciones limitadas a 400 caracteres.
    • Una condición obligatoria de aceptación de las normas ficticias, un campo oculto con el origen de la solicitud y botones de envío y restablecimiento.
    • Contacto con un segundo formulario independiente: nombre, correo, asunto obligatorio elegido entre varias opciones y mensaje de 20 a 500 caracteres.
    • Navegación común, enlaces a secciones internas y al menos un enlace externo a una fuente de información sobre naturaleza.

    Usa identificadores y nombres comprensibles. Los textos de disponibilidad y los códigos de actividad deben ser coherentes entre el catálogo y el formulario. No se pide sincronizar los dos formularios, calcular importes ni comprobar disponibilidad real.

    Comprueba: realiza una solicitud válida y un mensaje de contacto válido. Prueba también campos obligatorios vacíos, correo incorrecto, cantidad fuera de rango, fecha no válida y una actividad no disponible. Inspecciona los datos que envía cada formulario.

    Comprobaciones para todos los proyectos

    1. Abre cada página directamente y recorre todos los enlaces. Ninguno debe depender de una ruta absoluta de tu ordenador.
    2. Comprueba que las imágenes tienen texto alternativo y se cargan también desde las páginas de las subcarpetas.
    3. Revisa que cada tabla conserve una estructura coherente al utilizar rowspan o colspan.
    4. Recorre los formularios con Tab y pulsa sus etiquetas. Revisa nombres, valores y agrupación de radios.
    5. Intenta enviar datos no válidos y verifica que se impide el envío. Después envía datos válidos y revisa la URL.
    6. Restablece los formularios y comprueba los valores y selecciones iniciales.
