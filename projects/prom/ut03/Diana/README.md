# Diana

Proyecto base del ejercicio 3.42 de PROM UT3, importado del libro JavaFX
y revisado para JDK 25. Dibuja circulos concentricos alternando colores.
No incluye una solucion: completa los TODOs numerados del codigo.
Cada TODO coincide con un punto individual del enunciado HTML.

En IntelliJ IDEA, ejecuta el metodo main de DianaApp con el triangulo verde.
La clase esta en edu.masanz.da.ut3.app.

El paquete base es edu.masanz.da.ut3, con app para la aplicacion,
modelo para las clases de modelo cuando existen y util para Configuracion.
Cada proyecto es independiente, aunque comparta los paquetes con los demas.
La ventana, la captura de teclas y la animacion que existan vienen preparadas.
No cambies la infraestructura de JavaFX ni crees otras clases.
Trabaja en los metodos indicados por los TODOs, sin arrays ni colecciones.
Los constructores directos, accesores y dibujos sencillos ya suministrados
estan implementados. Los retornos provisionales no resuelven las tareas.
