# ComprenderClases

Proyecto base Maven para la UT2 de Programación.

Paquetes:

- `edu.masanz.da.ut2.modelo`: clases `Persona` y `Pelicula`.
- `edu.masanz.da.ut2.app`: clase `Main`.

El objetivo inicial es leer las clases dadas y entender atributos, constructores, getters, setters y métodos de acción.
