    Condicionales Simples

    En esta actividad trabajaremos los condicionales simples utilizando operadores como >, <, >= y <=. Aprenderemos a utilizar if, else if y else para evaluar condiciones básicas.

    Crearás proyectos donde implementarás condiciones sencillas para resolver problemas prácticos como verificar si un número es mayor o menor, si un objeto tiene ciertos atributos o si una persona cumple una serie de requisitos.

    Forma de trabajo en toda la tanda

    Resuelve todos los ejercicios de condicionales, for y while dentro del método main de una clase Main. Utiliza variables locales, constantes, expresiones y estructuras de control. Puedes emplear Scanner, Random y Math, pero no declares clases de modelo, atributos, constructores ni métodos auxiliares propios. Tampoco necesitas arrays ni colecciones.

    Los ejercicios están organizados en tres bloques, con sus subsecciones introductorias: condicionales (3.1–3.18), bucles for (3.19–3.33) y bucles while (3.34–3.41). Crea un proyecto independiente para cada ejercicio.

    3.1 Comparación de números

    Practica if, else if y else comparando dos números enteros.

    Cómo trabajaremos en estas actividades

    Crea un proyecto con una clase Main y su método public static void main(String[] args). Escribe toda la lógica dentro de main, utilizando variables locales, expresiones, condicionales y, cuando se soliciten, bucles. No declares atributos, constructores, métodos auxiliares ni clases de modelo. Tampoco necesitas arrays ni colecciones.

    Puedes utilizar clases de Java como Scanner, Random y Math. Los import necesarios se escriben antes de la declaración de Main. Estas normas se aplican a toda la tanda de ejercicios.

    En los primeros ejercicios puedes asignar los datos directamente a las variables y cambiarlos entre ejecuciones. Cuando se pida entrada por teclado, utiliza Scanner. Este ejemplo solo muestra cómo leer un entero:

    import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner teclado = new Scanner(System.in);
        System.out.print("Introduce un número entero: ");
        int numero = Integer.parseInt(teclado.nextLine());
        System.out.println("Has escrito: " + numero);
    }
}

    Para leer texto utiliza teclado.nextLine() y para un decimal, Double.parseDouble(teclado.nextLine()), escribiendo el punto como separador decimal. Por ahora puedes suponer que se introduce un dato del tipo solicitado; las comprobaciones del enunciado se refieren a sus valores.

    Qué debes hacer

    Declara dos variables locales de tipo int, numero1 y numero2. Compara sus valores y muestra exactamente uno de estos mensajes:

    • Si el primero es mayor: El primer número es mayor.
    • Si el segundo es mayor: El segundo número es mayor.
    • Si coinciden: Los dos números son iguales.

    Resuelve la comparación mediante condicionales, sin utilizar Math.max().

    Pruebas

    Ejecuta el programa con 8 y 3, 3 y 8, 5 y 5 y -2 y -7. Antes de ejecutar, anota qué mensaje esperas.

    Nombre del proyecto del ejercicio: UT3Ejer1Comparacion

    3.8 Juego de dados

    Decide quién gana una partida en la que un trío tiene prioridad sobre la suma.

    Qué debes hacer

    Representa a dos participantes mediante sus nombres y seis variables enteras locales: tres dados por participante. Todo el programa se desarrolla dentro de main.

    3.9 Batalla de robots

    Actualiza la vida de dos robots y decide si pueden continuar el combate.

    Qué debes hacer

    En main, representa a cada robot mediante variables locales para nombre, vida, ataque y defensa, diferenciándolas con los sufijos 1 y 2. La vida inicial será 100 y los valores de ataque y defensa serán enteros positivos.

    1. El robot 1 ataca al robot 2. Solo causa daño si su ataque supera la defensa rival.
    2. El daño es la diferencia entre ataque y defensa. Resta ese daño a la vida del defensor, sin dejarla por debajo de cero.
    3. Muestra el daño causado y la vida restante. Si el defensor llega a cero, anuncia su derrota.
    4. Si el robot 2 sigue vivo, responde una vez aplicando las mismas reglas al robot 1.
    5. Muestra el estado de ambos al terminar el intercambio.

    No declares una clase Robot ni un método de combate. Las comprobaciones y modificaciones de vida deben estar dentro de main.

    Pruebas y ampliación con bucles

    Prueba ataque inferior, igual y superior a la defensa, y un golpe que elimine al defensor. Después, como ampliación, repite los intercambios con while hasta que alguien pierda o se alcancen 20 rondas. Si ambos siguen vivos al llegar al límite, declara empate; así también termina un combate en el que nadie puede causar daño.

    3.10 Colisión entre rectángulos

    • Para datos válidos, comprueba si los intervalos se tocan o superponen en cada eje.

    Pruebas

    Trabajando con Math.random()

    En esta actividad vamos a aprender a utilizar la función Math.random(), que nos permite generar números aleatorios en Java. Este método es útil en una gran variedad de situaciones, como en juegos, simulaciones, sorteos, y mucho más.

    ¿Qué es Math.random()?

    El método Math.random() genera un número decimal aleatorio entre 0.0 (inclusive) y 1.0 (exclusivo). Sin embargo, podemos manipular el resultado para generar números aleatorios en rangos más amplios, como números enteros o números dentro de un rango específico.

    Aplicaciones Prácticas

    Durante los próximos ejercicios, utilizaremos Math.random() para desarrollar pequeños proyectos en los que se generen números aleatorios, como en la venta de boletos de lotería o la simulación de eventos aleatorios.

    ¿Por qué aprenderlo?

    El uso de números aleatorios es esencial en muchos programas y juegos. Generar números aleatorios nos permite simular situaciones inesperadas o simplemente introducir elementos impredecibles en nuestros proyectos.

    Vamos a experimentar con esta función a lo largo de varios ejercicios para que aprendas cómo funciona y cómo puedes manipular estos elementos para distintos propósitos.

    Trabajando con Switch

    En las siguientes actividades vamos a aprender a utilizar la instrucción switch en Java, la cual nos permite evaluar múltiples posibles casos basados en el valor de una variable y ejecutar diferentes bloques de código dependiendo del resultado.

    ¿Qué es switch?

    El bloque switch evalúa una expresión, compara su valor con diferentes case y ejecuta el código asociado al caso que coincida. Si no coincide ninguno, puede utilizarse una opción default para manejar los valores que no correspondan a los casos predefinidos.

    Aplicaciones Prácticas

    Durante los próximos ejercicios, emplearemos switch para manejar distintos escenarios, como en un menú de opciones, en la selección de operaciones matemáticas o en la gestión de empleados con diferentes roles y salarios.

    ¿Por qué aprenderlo?

    La instrucción switch es útil cuando tienes múltiples opciones o resultados posibles para una variable. Es una alternativa más clara y eficiente a las estructuras if-else múltiples, mejorando la legibilidad de tus programas.

    Vamos a explorar diferentes formas de utilizar switch a lo largo de varios ejercicios para que aprendas cómo aplicarlo en proyectos reales.

    Bucles for

    En esta actividad trabajaremos con bucles for, una estructura fundamental en programación que nos permite repetir un bloque de código un número determinado de veces.

    El bucle for se utiliza para realizar tareas repetitivas como imprimir secuencias numéricas, recorrer una serie de datos o generar patrones.

    Veremos la estructura básica del bucle:

    for (inicialización; condición; actualización) {
    // Bloque de código que se ejecuta en cada iteración
}

    Bucles Anidados

    En estas actividades, aprenderás a utilizar bucles anidados: un bucle dentro de otro. Los emplearemos para generar patrones de texto por filas y columnas, sin almacenar una matriz.

    Un bucle anidado sigue la siguiente estructura:

    for (inicialización1; condición1; actualización1) {
    for (inicialización2; condición2; actualización2) {
        // Bloque de código anidado
    }
}

    Este tipo de bucles permite resolver problemas más complejos, como:

    • Imprimir patrones en forma de pirámides o figuras geométricas.
    • Realizar cálculos sobre tablas de datos.
    • Controlar por separado cuántas filas se imprimen y qué aparece en cada columna.

    En los ejercicios de esta unidad, aplicarás bucles anidados para resolver retos que involucren repeticiones dentro de repeticiones, aumentando así la complejidad y el control sobre las estructuras de datos y el flujo de tu código.

    Bucles while

    En estas actividades vamos a aprender a utilizar el bucle while, otra estructura fundamental en programación que nos permite repetir un bloque de código mientras se cumpla una condición.

    El bucle while es especialmente útil para repetir acciones sin conocer de antemano cuántas veces necesitaremos ejecutarlas. Tanto for como while comprueban una condición, pero solemos elegir for cuando controlamos una cantidad de repeticiones y while cuando esperamos que ocurra algo.

    Como en el resto de la tanda, escribe toda la lógica en Main.main, con variables locales y sin clases de modelo ni métodos auxiliares propios.

    Estructura básica del bucle while

    while (condición) {
    // Bloque de código que se ejecuta mientras la condición sea verdadera
}

    En cada iteración, el bucle while evalúa la condición antes de ejecutar el bloque de código. Si la condición es true, el bloque de código se ejecuta y, al finalizar, se vuelve a evaluar la condición. Si es false, el bucle se detiene.

    Ejercicios prácticos

    En los ejercicios de esta actividad, implementarás bucles while para resolver problemas como:

    • Imprimir secuencias de números bajo ciertas condiciones.
    • Generar sumas acumulativas hasta alcanzar un valor objetivo.
    • Simular procesos que deben repetirse hasta que ocurra un evento.

    Nota importante

    Recuerda que el bucle while puede llevar a bucles infinitos si la condición nunca se vuelve falsa. Asegúrate de que en algún momento la condición se actualizará para detener el bucle.

    3.41 Número Primo Más Cercano

    Solicita un número entero y busca el número primo más cercano, combinando bucles para explorar candidatos y comprobar sus divisores.

    ¿Qué es un Número Primo?

    Un número primo es un número mayor que 1 que solo puede dividirse de manera exacta por sí mismo y por 1. Es decir, no tiene divisores adicionales. Por ejemplo, 2, 3, 5, y 7 son números primos.

    Los números primos son fundamentales en muchos campos de las matemáticas y la informática, y encontrar números primos es una habilidad importante.

    ¿Qué Harás en Este Ejercicio?

    Tu objetivo será desarrollar un programa que siga estos pasos:

    • Pedir al usuario que introduzca un número.
    • Buscar el número primo más cercano a ese número (puede ser menor, igual o mayor).
    • Mostrar el número primo encontrado.

    Para encontrar el primo más cercano, el programa deberá verificar, por cada número cercano, si cumple con las condiciones de ser primo hasta localizar el número que esté más próximo.

    Si el número introducido ya es primo, el resultado será ese mismo número. Si dos primos están a la misma distancia, muestra el menor. Para cualquier valor menor o igual que 2, el más cercano es 2. Para mantener las pruebas manejables, trabaja con entradas entre -100000 y 100000; fuera de ese rango muestra un aviso.

    Resuelve la búsqueda y las comprobaciones de divisibilidad en main, con bucles anidados, sin declarar un método esPrimo ni utilizar arrays o colecciones. Prueba 2, 4, 8, 11, 12, 0 y un valor negativo.
