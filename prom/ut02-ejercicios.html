    Objetos y clases

    2.1 Comprender clases dadas

    Antes de utilizar objetos en Main, necesitamos aprender a leer una clase y reconocer sus partes principales.

    Objetivo

    En esta actividad no vamos a diseñar clases desde cero. Vamos a observar dos clases ya creadas, Persona y Pelicula, para entender cómo están compuestas.

    Después responderemos preguntas sobre atributos, constructores, métodos, getters y setters. La idea es distinguir qué partes de la clase almacenan información, qué partes permiten crear objetos y qué partes permiten usar o modificar esos objetos.

    Proyecto base

    Descarga el proyecto Maven base y ábrelo con IntelliJ IDEA. El proyecto contiene las clases Persona y Pelicula ya creadas, además de una clase Main mínima para empezar a probar.

    La estructura de paquetes es la siguiente:

    • edu.masanz.da.ut2.modelo: clases Persona y Pelicula.
    • edu.masanz.da.ut2.app: clase Main.

    En este primer ejercicio no debes modificar las clases. Tu tarea principal es leerlas, entender sus partes y responder a las preguntas.

    Preguntas de comprensión

    1. ¿Qué sección de cada clase representa los atributos?

    Cuidado, spoiler

    Los atributos son las variables declaradas al inicio de cada clase con private. Representan el estado que guarda cada objeto.

    private String nombre;
private int edad;
private String profesion;

    2. ¿Cuántos atributos tiene la clase Persona? ¿Y la clase Pelicula?

    Cuidado, spoiler

    Persona tiene 3 atributos: nombre, edad y profesion.

    Pelicula tiene 7 atributos: titulo, anioEstreno, director, actrizPrincipal, actorPrincipal, duracionMinutos y estrenada.

    3. ¿De cuántas maneras diferentes podemos crear una Persona?

    Cuidado, spoiler

    De 2 maneras, porque la clase tiene 2 constructores.

    Persona persona1 = new Persona("Ane");
Persona persona2 = new Persona("Ane", 32, "Directora");

    4. ¿De cuántas maneras diferentes podemos crear una Pelicula?

    Cuidado, spoiler

    De 2 maneras, porque la clase tiene 2 constructores.

    Persona directora = new Persona("Ane", 32, "Directora");
Persona actriz = new Persona("Nerea", 28, "Actriz");
Persona actor = new Persona("Iker", 30, "Actor");

Pelicula pelicula1 = new Pelicula("La noche del código", directora);
Pelicula pelicula2 = new Pelicula("La noche del código", 2026,
        directora, actriz, actor, 120);

    5. ¿Qué constructores piden menos información? ¿Qué valores se asignan por defecto en esos casos?

    Cuidado, spoiler

    Los constructores cortos son Persona(String nombre) y Pelicula(String titulo, Persona director).

    En Persona, la edad queda en 0 y la profesión en "Sin indicar". En Pelicula, el año y la duración quedan en 0, y estrenada queda en false.

    6. ¿Qué métodos sirven únicamente para obtener información de los atributos?

    Cuidado, spoiler

    Son los getters: getNombre, getEdad, getProfesion, getTitulo, getAnioEstreno, getDirector, getActrizPrincipal, getActorPrincipal, getDuracionMinutos e isEstrenada.

    String titulo = pelicula.getTitulo();
int edad = persona.getEdad();
boolean yaEstrenada = pelicula.isEstrenada();

    7. ¿Qué métodos sirven únicamente para modificar directamente atributos?

    Cuidado, spoiler

    Son los setters, los métodos que empiezan por set. Asignan directamente un nuevo valor a un atributo.

    persona.setEdad(33);
pelicula.setTitulo("Nuevo título");
pelicula.setDuracionMinutos(125);

    8. ¿Por qué en Pelicula aparece isEstrenada() en lugar de getEstrenada()?

    Cuidado, spoiler

    Porque estrenada es un atributo boolean. En Java es habitual que los getters de booleanos empiecen por is.

    9. ¿Qué métodos realizan acciones o modifican el estado de los objetos?

    Cuidado, spoiler

    cumplirAnios, presentarse, estrenar, retrasarEstreno y obtenerResumen son métodos de acción o comportamiento.

    persona.cumplirAnios();
pelicula.estrenar(2026);
pelicula.retrasarEstreno();

    10. ¿Qué atributos de Pelicula son de tipo Persona?

    Cuidado, spoiler

    Son director, actrizPrincipal y actorPrincipal.

    private Persona director;
private Persona actrizPrincipal;
private Persona actorPrincipal;

    11. ¿Qué significa que una película tenga un director, una actrizPrincipal y un actorPrincipal de tipo Persona?

    Cuidado, spoiler

    Significa que la película no guarda solo textos para esas personas, sino referencias a objetos completos de la clase Persona.

    12. ¿Qué método de Pelicula utiliza un método de la clase Persona?

    Cuidado, spoiler

    obtenerResumen() utiliza director.getNombre(), es decir, llama a un método de un objeto Persona.

    return titulo + " es una película dirigida por "
        + director.getNombre() + ".";

    13. ¿Qué diferencia hay entre cambiar el título con setTitulo(...) y estrenar una película con estrenar(...)?

    Cuidado, spoiler

    setTitulo(...) solo cambia un atributo. estrenar(...) modifica dos partes del estado: el año de estreno y si la película está estrenada.

    pelicula.setTitulo("Otro título");
pelicula.estrenar(2026);

    14. ¿Qué información mínima necesitas para crear una película usando el constructor más corto?

    Cuidado, spoiler

    Necesitas un titulo y un director.

    Persona directora = new Persona("Ane");
Pelicula pelicula = new Pelicula("La noche del código", directora);

    15. ¿Qué información mínima necesitas para crear una persona usando el constructor más corto?

    Cuidado, spoiler

    Necesitas un nombre.

    Persona persona = new Persona("Ane");

    Pista antes de mirar las respuestas

    Intenta clasificar cada parte de las clases en una de estas categorías:

    • Atributos: guardan el estado del objeto.
    • Constructores: permiten crear objetos.
    • Getters: devuelven información.
    • Setters: modifican directamente atributos.
    • Métodos de acción: hacen algo más significativo que devolver o asignar un valor.
