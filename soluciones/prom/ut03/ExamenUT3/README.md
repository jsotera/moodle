# Examen UT3 - Proyecto resuelto

Solución completa del examen del laberinto. Ejecuta app.Main y elige el mapa
1, 2 o 3. El enunciado está incluido en el ZIP, pero no enlaza a esta solución.

Mantiene las mismas clases, firmas, mapas y reglas que la base del alumnado.
Mapa integra el personaje y las reglas. util.Conf contiene los tres escenarios.
Las casillas son String y obtenerCasilla devuelve null fuera de los límites.
La opción 1 usa un solo botiquín. El control de excepciones está en la selección
del mapa. La opción 2 restaura todos los datos y la 3 solo muestra el menú.

Esta versión no contiene TODO pendientes. No distribuirla como proyecto base.
